# Audit update — Strategy Lab terminal results

Date: 2026-08-05
Corrective patch: 5
Findings: `SL-COR-003`, `SL-COR-004`, and `SL-COR-007`

## Source remediation

The normal worker path no longer ends unconditionally as `PARTIAL`. The final shortlist is now the source of truth:

- non-empty shortlist -> `state=completed`, `outcome=SUCCESS`;
- empty valid shortlist -> `state=completed`, `outcome=NO_CANDIDATE`.

Other terminal mappings are explicit:

- accessible clean baseline -> `completed / TARGET_ACCESSIBLE`;
- controlled cancel or bounded incomplete prerequisite result -> `completed / PARTIAL`;
- timeout -> `error / TIMEOUT`;
- internal failure -> `error / ERROR`;
- restoration verification failure -> `error / RESTORE_FAILED`.

Stage 99 is `PASS` only for completed outcomes and `FAIL` for error outcomes. A restoration failure overrides the requested result and cannot be represented as normal completion.

Final user text is generated by one result module from language, mode, outcome, cancellation state, and shortlist count. Cascading message-module assignment no longer controls final reporting.

## Automated evidence

`scripts/test-strategy-lab-terminal-result.sh` exercises the complete terminal mapping matrix and asserts persisted JSON, stage-99 status, and localized message content. Existing lifecycle expectations are updated to reject the stale default `PARTIAL` and completed-error behavior.
