## Approved scope and present boundary

The owner instructed development of **Remove Additional Resources** on 25 October 2026, following the [approved specification](../architecture/ZAPRET2_EXTRA_RESOURCES_REMOVE_SPEC.md) and [13-stage implementation plan](../architecture/ZAPRET2_EXTRA_RESOURCES_REMOVE_PLAN.md).

Stage 1 (merged and source/FreeBSD15 CI-qualified in [PR #577](https://github.com/Tolian82/os-zapret2-restyle/pull/577)) adds a **read-only** Git HEAD resource removal plan: inspect installed Lua/BIN, verify upstream and current content, protect saved Config and manifest witnesses, compute the exact direct non-upstream files, and return bounded digest-bound counts/identities. The output explicitly marks compatibility **unknown** and authorization **false**.

Stage 2 groundwork builds a private upstream-only Lua/BIN resource view and tests the existing native Blob resolver against that future file set, without modifying live resources. `v0.5.9_3` tests real full native Strategies candidate production against that view: multiple `--new` profiles, Extra Arguments, positive upstream BIN, rejected extra BIN and Lua init paths. `v0.5.9_4` adds read-only original saved XML/OPNsense-rendered `zapret.conf` parity via existing `voice_native_saved_pair_guard`, attested on both sides of the temporary view. This is a **guarded input** only: it does not yet acquire native FD9, render a real locked saved pair, invoke the engine or establish Lua export/dependency compatibility. `v0.5.9_5` adds an import-only, already-locked native saved Config inode snapshot and the original detached OPNsense `zapret.conf` generator (`shared_apply_render.render_detached`) as a prospective source view, with mandatory lifecycle/Config/generation double checks; offline fixtures use mock lifecycle owner and real Config flock. `v0.5.9_6` connects a **root-only internal native read-only preview**: synchronous original setup.lock via extra_resources_launcher.sh, original FD9 via zapret_service.sh, exclusive OPNsense Config flock via extra_resources_saved_route.py, native detached OPNsense rendering and upstream-only Git/Config resource inventory, plus fail-closed common Apply journal. No configd/GUI action; no engine candidate/Lua execution proof or compatible result. Voice OFF drafts and service behavior remain unverified.

**No removal operation exists yet.** The Strategies/Voice upstream-only compatibility gates, combined native compilation, full snapshot/rollback, shared FD9 native lifecycle, authenticated API, Advanced-only GUI, state/cache reconciliation, package testing and owner OPNsense acceptance remain unimplemented. Never infer service safety or successful bypass from Stage 1 source tests.
