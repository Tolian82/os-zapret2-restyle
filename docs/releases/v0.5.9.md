## Superseding acceptance decision (26 October 2026)

The owner **cancelled Jail and the exhaustive isolated exact-engine/Lua proof architecture for Remove**. The trial must use the **same** common GUI Apply compiler (`shared_apply_prepare_service()` and `orchestrator_build_release(..., shared-candidate)`) on the saved Config AFTER quarantine, not legacy Voice-refusing start or old cached-release restart. All current/future hostlist, ipset, placeholder, managed targets, Lua/BLOB, and Voice fields are resolved by their already-existing modules; Remove must NOT separately encode or copy any such list/field/argument logic. Remove now verifies what a user would verify when using the existing GUI: original native Strategies + saved Voice candidate checks, then after transaction-protected Stop and temporary quarantine of non-upstream Lua/BIN, a **real installed** common service Apply/Start with the saved Config and current native post-Start owner/IPFW evidence. Success commits removal; any failure must restore original resources and service or report `RESTORE_FAILED` with retained journal. Real network DPI outcomes and voice-call success are explicitly outside acceptance. No rewrite of Exclude Domains/hostlist-exclude; future ipset-exclude GUI is deferred. Source _23 retires the unused Jail support/tests; historical notes below describe cancelled work and do not impose active test gates. Stage 1 remains complete; Stage 2–5 active native implementation and owner appliance tests remain open.
