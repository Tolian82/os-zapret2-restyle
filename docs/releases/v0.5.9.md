The output explicitly marks compatibility **unknown** and authorization **false**.

Stage 2 groundwork builds a private upstream-only Lua/BIN resource view and tests the existing native Blob resolver against that future file set, without modifying live resources. `v0.5.9_3` tests real full native Strategies candidate production against that view: multiple `--new` profiles, Extra Arguments, positive upstream BIN, rejected extra BIN and Lua init paths. `v0.5.9_4` adds read-only original saved XML/OPNsense-rendered `zapret.conf` parity via existing `voice_native_saved_pair_guard`, attested on both sides of the temporary view. This is a **guarded input** only: it does not yet acquire native FD9, render a real locked saved pair, invoke the engine or establish Lua export/dependency compatibility. Production saved-config/engine, Voice OFF drafts and service behavior remain unverified.

**No removal operation exists yet.** The Strategies/Voice upstream-only compatibility gates, combined native compilation, full snapshot/rollback, shared FD9 native lifecycle, authenticated API, Advanced-only GUI, state/cache reconciliation, package testing and owner OPNsense acceptance remain unimplemented. Never infer service safety or successful bypass from Stage 1 source tests.
