## What's new since v0.6.4

- Native Zapret2 `!` (local exclusion) and `^` (exact-domain) in YouTube/User HOSTLIST, with safe installed-runtime compatibility and unchanged global Exclude policies.
- Unified Python `domain_policy.py` and existing `ipset_policy.py`, thin PHP/shell bridges, correct `--new` native profile order, multiple payload/Lua handlers, resolved-list duplicate protection, and native `dvtws2 --dry-run`.
- Full bilingual RU/EN Strategies and Voice field labels, validation, help, Full Help, cached Lua/BIN resource inventory and F5 value retention.
- Strict read-only Validate and Preview of unsaved profiles, L7/port/target/payload information without persistent Config, FD9, IPFW, Voice or service mutation.
- Laboratory top Help row styled as OPNsense's native gray form row with 13px reversible guidance. Existing Standard/Extended Lab behavior and WAN-first shared lifecycle retained.

Owner fully accepted [#936](https://github.com/Tolian82/os-zapret2-restyle/issues/936) P0–P6 by manual functional/visual checks on real OPNsense; joint `^t.me` + `^youtube.com` Apply was accepted on installed `0.6.4_48.pkg`, Lab Help appearance accepted on installed `0.6.4_50.pkg` ([#1084](https://github.com/Tolian82/os-zapret2-restyle/issues/1084)). This is not installation proof of newly built `0.6.5_1.pkg`.

**Excluded from this release:** automatic service restart, scheduler and its Advanced-only field. Owner deferred it to future [#1052](https://github.com/Tolian82/os-zapret2-restyle/issues/1052); it is not a #936 or release blocker.

## Installation and update

Target: **OPNsense 26.7 / FreeBSD:15:amd64**. Plugin and upstream Zapret2 runtime are independently managed. After stable publication, install/upgrade `os-zapret2-restyle` using **System → Firmware → Plugins** and the project OPNsense pkg repository. If not yet registered, on root shell:

```sh
fetch -o /usr/local/etc/pkg/repos/zapret2-restyle.conf https://tolian82.github.io/os-zapret2-restyle/zapret2-restyle.conf
pkg update -f
```

Review native dependency changes; do not enable stock FreeBSD repos, bypass pkg hooks, overwrite Config or disable PF. Install/select the upstream `dvtws2` runtime separately using the existing Zapret2 Service setup.

Release is complete only when immutable [v0.6.5](https://github.com/Tolian82/os-zapret2-restyle/releases/tag/v0.6.5) tag matches exact release-preparation merge; published [`os-zapret2-restyle-0.6.5_1.pkg`](https://github.com/Tolian82/os-zapret2-restyle/releases/download/v0.6.5/os-zapret2-restyle-0.6.5_1.pkg) and `SHA256SUMS` have verified actual bytes/ABI/SHA; matching Pages/pkg repository exposes `FreeBSD:15:amd64/` package, `meta.conf`, `data.pkg`, `packagesite.pkg`, checksums, and `zapret2-restyle.conf`.
