- Strategies one global `Exclude IPSet` for all executable ordinary/Voice profiles, preserving domain-only `Exclude Domains`, template/import and additional Lua/BIN assembly, and native Config/shared Apply ownership.
- IPv4/IPv6 managed target and five Voice destination lists; canonical CIDRs and strict refusal of `/0` or complementary full-family network unions in all user-managed IP lists.
- Dual-stack native IPFW table/capture and safe previous-state restoration, single shared `dvtws2`.

- Existing optional Extra Resources Install/Advanced Remove and two-column Lua/BIN Full Help; no new Voice/P2P destination-any UDP mode or second runtime.
