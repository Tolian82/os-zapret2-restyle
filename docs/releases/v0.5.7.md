- The package stages a private binary and libcurl, bundled licenses, a single plain Chrome profile selected from package wrappers, and build provenance.
- Production HTTP/HTTPS still uses the existing client. Stage 2 migrates Model C and wires pre-stop client readiness.
- PR, package and owner-live acceptance must be verified separately; full stable release is not authorized.
