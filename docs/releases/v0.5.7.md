## Install/update

For OPNsense root console (run only once to register the repository):

```sh
fetch -o /usr/local/etc/pkg/repos/zapret2-restyle.conf https://tolian82.github.io/os-zapret2-restyle/zapret2-restyle.conf
pkg update -f
```

Then use **System → Firmware → Plugins** for `os-zapret2-restyle`. Plugin package version and separately selected upstream Zapret2 engine release have independent lifecycles. See [README](../../README.md), [current state](../PROJECT_STATE.md), and [Stage 6 owner evidence](../verification/evidence/2026-10-22-v0.5.6_17-stage6-installed-hygiene.md).
