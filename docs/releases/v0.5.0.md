## Summary

v0.5.0 promotes the completed and owner-live accepted `v0.4.x` development line into the stable Web/pkg release. The release-preparation change itself does not alter runtime behavior: it advances the project line to `0.5.0_1`, rolls documentation into `v0.5.x`, and presents the user-visible feature set accumulated and verified on the published `v0.4.1_23` candidate.

The centerpiece of this release is **Strategy Lab**: an OPNsense-native automated search and verification pipeline for finding Zapret2 DPI-bypass strategies against a blocked domain or IPv4 destination.

## Highlights

- Production Strategy Lab Stage 60 is **Model C only**; the old automatic Model-B/Model-A production replay has been removed.
- Candidate execution uses deterministic native Zapret2 profiles, controlled source-port attribution, finite adaptive budgets, bounded cleanup and exact Stage-90 service restoration.
- The Laboratory accepts both domains and canonical IPv4 targets.
- IPv4 targets can carry a separate optional Host/SNI identity while remaining pinned to the entered destination IP.
- Working fixed-IP profiles emit `--ipset-ip=<target>` and are replayed exactly before recommendation.
- Authenticated/intercepted HTTP `4xx`/`5xx` responses remain valid DPI-path evidence instead of being misclassified as bypass failure.
- Bare IPv4 certificate-identity failures produce truthful `PARTIAL` guidance asking for Host/SNI.
- QUIC execution is explicitly controlled by the persisted **Enable QUIC** setting; the owner verified that the saved state survives Laboratory reload/revisit.
- Bare-IP QUIC without Host/SNI is skipped before execution rather than falsely reported as tested.
- Extended mode can test Generic UDP independently from Host/SNI and QUIC.
- Russian/English Laboratory presentation, native OPNsense layout, strategy result rendering, cleanup and restoration have owner-live coverage.
- The Zapret2 Service manager continues to install, update, reinstall or downgrade the upstream bol-van/zapret2 runtime transactionally.
