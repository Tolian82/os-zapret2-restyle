## Fixed

- `+POST_INSTALL` now registers `os-zapret2-restyle` in OPNsense firmware plugin state.
- `rc.configure_plugins` is invoked with the lifecycle mode `POST_INSTALL` rather than the plugin name.
- Package installation fails instead of silently continuing when the OPNsense registration or plugin-configuration helper is unavailable or fails.
- Focused lifecycle CI coverage prevents regression of the registration contract.
