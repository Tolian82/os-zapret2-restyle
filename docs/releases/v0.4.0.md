==================================================
SUMMARY
==================================================

v0.4.0 is the stable Strategy Lab release. It promotes the owner-tested `0.3.3_27`
runtime line after the Python migration and its live corrective closure, without adding
new runtime behavior in the release-preparation patch itself.

Strategy Lab now runs as a bounded asynchronous Diagnostics workflow with persisted
progress/evidence, isolated candidate execution, replay/stability validation, structured
results, cancellation, cleanup, and exact restoration of the pre-test Zapret2 state.

==================================================
HIGHLIGHTS
==================================================

- Python 3.13 owns the automated Strategy Lab state, stage machine, finite probes,
  candidate search, replay, final results and Diagnostics status reconciliation.
- Audited FreeBSD mutations and private circular-session state remain narrow shell
  boundaries.
- Standard/Extended evidence covers TLS 1.3, TLS 1.2, HTTP, fixed QUIC capability and
  validated generic UDP paths with capability-aware IPv4/IPv6 handling.
- Corrective work hardens cancellation, time budgets, restoration, candidate ownership,
  persisted reload, retention, Settings coordination, CI and FreeBSD 15 packaging.
- `_26` candidate-local failure aggregation and `_27` live DNS deadlines close the two
  final release-selected post-migration defects.
- The separately approved adaptive native-Zapret2 search redesign remains future
  `_28`–`_33` work and is not presented as v0.4.0 executable behavior.
