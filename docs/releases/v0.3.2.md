# os-zapret2-restyle v0.3.2

Release date: 2026-08-03

Package:
`os-zapret2-restyle-0.3.2_1.pkg`

Target:
OPNsense 26.7 / FreeBSD 15 amd64

==================================================
SUMMARY
==================================================

v0.3.2 is a governance and engineering-documentation release. It does not change the
plugin runtime, GUI behavior, service lifecycle, or diagnostics implementation from the
owner-verified v0.3.1 baseline.

The release makes GitHub delivery more deterministic and reduces unnecessary commits,
pull-request events, failed protocol checks, and repeated workflow runs.

==================================================
CHANGED
==================================================

- Added the final GitHub publication specialist document to the mandatory reading
  order.
- Replaced the normal Draft → Ready path with one ready pull request and one complete
  check set.
- Required the package-candidate pull-request title to be calculated before the PR is
  opened.
- Distinguished the pull-request title from the release squash subject.
- Required multi-file API publication through blobs, one tree, and one atomic commit.
- Required failed delivery cycles to be closed and replaced with a clean cycle instead
  of repair commits, force-push, title edits, or repeated retriggers.
- Added explicit delivery-stage and release-authority gates.
- Made release progression forward-only: published tags, releases, assets, and versions
  remain immutable and are never rolled back or reused.
- Required complete public release/pkg-repository verification before installation
  instructions are issued.

==================================================
VERIFIED BASELINE
==================================================

The project owner personally checked v0.3.1 / package `0.3.1_1` and confirmed that
everything works correctly. DIAG-002 is recorded as resolved and live verified.

v0.3.2 packages the same accepted runtime source with updated project version and
engineering documentation.
