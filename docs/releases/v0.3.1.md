# os-zapret2-restyle v0.3.1

Release date: 2026-08-03

Package:
`os-zapret2-restyle-0.3.1_1.pkg`

Target:
OPNsense 26.7 / FreeBSD 15 amd64

==================================================
SUMMARY
==================================================

v0.3.1 is a focused diagnostics bug-fix release.

It fixes the Test Domain Connectivity result field becoming empty when the tested
destination is unreachable or blocked. Positive and negative probes now use the same
complete multiline report format.

==================================================
FIXED
==================================================

- Preserved DNS resolution output for negative connectivity results.
- Preserved HTTPS status, remote IP, TLS verification value, and timing output.
- Preserved final classifications for:
  - TLS handshake failure;
  - connection reset;
  - timeout;
  - DNS resolution failure;
  - connection refusal;
  - other curl failures.
- Added an explicit API error when configd returns no diagnostic output instead of
  treating an empty string as successful data.

==================================================
VERIFICATION
==================================================

The release includes focused automated coverage for:

- timeout;
- connection reset;
- generic non-zero curl failure;
- invalid domain input;
- the MVC empty-response guard.

The standard release pipeline additionally validates shell, PHP, and XML syntax,
runs the existing regression suite, builds the package inside FreeBSD 15, verifies the
package manifest, and generates the FreeBSD:15:amd64 pkg repository.
