==================================================
SUMMARY
==================================================

v0.3.1 is a focused diagnostics bug-fix release.

It fixes the Test Domain Connectivity result field becoming empty when the tested
destination is unreachable or blocked. Positive and negative probes use the same
complete multiline report format.

==================================================
FIXED
==================================================

- Preserved DNS resolution output for negative connectivity results.
- Preserved HTTPS status, remote IP, TLS verification value, and timing output.
- Preserved final classifications for TLS handshake failure, connection reset,
  timeout, DNS resolution failure, connection refusal, and other curl failures.
- Added an explicit API error when configd returns no diagnostic output instead of
  treating an empty string as successful data.

==================================================
VERIFICATION
==================================================

Automated coverage includes:

- timeout;
- connection reset;
- generic non-zero curl failure;
- invalid domain input;
- the MVC empty-response guard.

The release pipeline validated shell, PHP, and XML syntax, ran the regression suite,
built the package inside FreeBSD 15, verified its manifest, and generated the
FreeBSD:15:amd64 pkg repository.

On 2026-08-03 the project owner personally checked package `0.3.1_1` and confirmed that
everything in the release works correctly. DIAG-002 is therefore classified as resolved
and live verified.
