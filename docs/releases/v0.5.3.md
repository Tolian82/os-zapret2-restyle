# os-zapret2-restyle v0.5.3

**Статус: исправление исходников подготовлено; релиз не опубликован.** `PLUGIN_REVISION=2`, candidate `v0.5.3_2`; package candidate `os-zapret2-restyle-0.5.3_2.pkg`.

## Цель исправляющей поставки

Устранить подтверждённый отказ открытия Voice Transmission в опубликованном `0.5.2_194`: URL `/ui/zapret/voice` не имеет соответствующего UI-контроллера. Сохранить полное ТЗ, пять сервисов и общий backend со «Стратегиями». Поставка через существующий GUI/pkg-репозиторий одобрена владельцем как шаг [плана](../architecture/VOICE_TRANSMISSION_COMPLETION_PLAN.md).

## Граница готовности

В `_1` записаны правила наблюдаемого результата и план. В `_2` добавлен штатный UI VoiceController, устранён несоответствующий маршрут в IndexController, исправлен устаревший GUI тест и добавлена проверка настоящим Router OPNsense 26.7 для исходников/извлечённого `.pkg`. Результаты CI/публикации и установка исправления пока не подтверждены. Доступность страницы, сохранение/Apply/boot и голосовая связь принимаются раздельно по [контролю приёмки](../VOICE_CODE_COMPLETION_GATE.md).

До фактического открытия установленной страницы: **исправление подготовлено; работа установленной страницы не подтверждена**. Эта фраза применяется после подготовки самого исправления; на текущей документационной границе исправление только запланировано.
