# os-zapret2-restyle v0.5.3

**Статус: полный релиз `v0.5.3_2` опубликован 17.10.2026; разрабатывается новый кандидат.** `PLUGIN_REVISION=4`, candidate `v0.5.3_4`; package candidate `os-zapret2-restyle-0.5.3_4.pkg`.

## Цель исправляющей поставки

Устранить подтверждённый отказ открытия Voice Transmission в опубликованном `0.5.2_194`: URL `/ui/zapret/voice` не имеет соответствующего UI-контроллера. Сохранить полное ТЗ, пять сервисов и общий backend со «Стратегиями». Поставка через существующий GUI/pkg-репозиторий одобрена владельцем как шаг [плана](../architecture/VOICE_TRANSMISSION_COMPLETION_PLAN.md).

Исходники и извлечённый FreeBSD 15 пакет проверены в [CI #39023792241](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39023792241): Voice, Project и package завершились успешно. Источник `_2` интегрирован в `main` коммитом [`92a96ae`](https://github.com/Tolian82/os-zapret2-restyle/commit/92a96ae26235d5c3bad8492a00b2b60563722779). Публикация подтверждена: тег `v0.5.3` указывает на точный release-preparation merge `376616af`, [GitHub Release](https://github.com/Tolian82/os-zapret2-restyle/releases/tag/v0.5.3) содержит пакет `os-zapret2-restyle-0.5.3_2.pkg` и `SHA256SUMS`, [workflow #39024503035](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39024503035) успешно создал FreeBSD:15:amd64 pkg repository и опубликовал GitHub Pages. [Детали](../verification/evidence/2026-10-17-v0.5.3-release-publication.md). Владелец установил `_2` и подтвердил открытие Voice, но обнаружил дефекты русской справки и WAN. Сохранение/Apply/boot и голосовая связь принимаются раздельно по [контролю приёмки](../VOICE_CODE_COMPLETION_GATE.md).

Владелец установил `_3`: RU справка, выбор WAN и проверка синтаксиса работают. `setup_status` сообщает started, `voice_inspect` — uninitialized, UI неверно показывает «Неизвестно», а `voice_lifecycle_inspect` возвращает `Execute error` без причины. `_4` исправляет только отображение статуса и диагностику отказа; Voice Apply/звонки остаются неподтверждёнными.

### `v0.5.3_4`: уточнение после диагностики на установленном OPNsense 26.7.7

Read-only инспектор `voice_lifecycle_inspect` отказал с `VoiceLifecycleRouteError: unsafe or replaced native Config inode`. Подтверждённый по upstream OPNsense 26.7 системный владелец `/conf/config.xml` — `wwwonly:wheel`, но первоначальная версия требовала `root:wheel`. Точечное исправление `_4` применено и к read-only draft preview, сохранив проверки inode, nlink, путь, FD9 и Config flock; без изменения runtime/IPFW, Config и общего Apply. [CI #39038290885](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39038290885) Voice/Project/FreeBSD pkg успешен, пакет [0.5.3_4](https://github.com/Tolian82/os-zapret2-restyle/releases/download/v0.5.3_4/os-zapret2-restyle-0.5.3_4.pkg) опубликован как testing prerelease [workflow #39038954522](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39038954522), SHA-256 `cba1c1a68a36a4d0cfbe61312157da338c386f9cde20e1395ada5e9393a0f37d`. GitHub Actions создал бинарник и evidence-ветку, но не смог открыть docs PR из-за отсутствия разрешения GitHub Actions; PR #339 открыт подключённым GitHub инструментом. Стабильный v0.5.3 и Pages pkg-репозиторий не затронуты. Повторной установки и результата инспектора на `_4` пока нет.
