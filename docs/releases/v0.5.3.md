**Статус: полный релиз `v0.5.3_2` опубликован 17.10.2026; разрабатывается новый кандидат.** `PLUGIN_REVISION=10`, candidate `v0.5.3_10`; package candidate `os-zapret2-restyle-0.5.3_10.pkg`.

## Цель исправляющей поставки

Устранить подтверждённый отказ открытия Voice Transmission в опубликованном `0.5.2_194`: URL `/ui/zapret/voice` не имеет соответствующего UI-контроллера. ### `v0.5.3_5`: следующий блокирующий дефект GUI Apply

Владелец установил `_4`, подтвердил корректный статус общей службы и исправленный read-only lifecycle inspector. Теперь UI показывает на WAN общую ошибку подготовки и сообщение неопределённого результата применения, при этом сохранённые Voice-профили OFF и Voice/IPFW uninitialized. Найдена воспроизводимая классификационная ошибка PHP: любой `Throwable` до dispatch `zapret shared_apply` помечался как потенциально выполненный Apply. В `_5` корректируется только классификация до/после FD9 и диагностическое обозначение безопасной стадии без утечки пользовательской Config; post-dispatch остаётся fail-closed. Исходная причина ошибки на устройстве неизвестна. [проверочный пакет `_5`](https://github.com/Tolian82/os-zapret2-restyle/releases/download/v0.5.3_5/os-zapret2-restyle-0.5.3_5.pkg) опубликован через [публикация #39043699207](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39043699207), SHA-256 `3c4ca5acf76e22f0d0fc16c823849bc363030f137e36d1bea8c2bc2e1613b7da`. [CI #39042954730](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39042954730) успешно подтвердил Voice/Project/FreeBSD15 pkg; стабильный v0.5.3 и Pages pkg repository неизменны. ### v0.5.3_7 — подтверждённый PHP POSIX blocker

На установленной `_6` GUI Validate прошёл, `shared-apply-run voice` отдаёт rc69, saved Voice OFF, native work roots отсутствуют. Прямой PHP FD9 attestor завершился Fatal Error `undefined posix_geteuid()` (rc255); предшествующие `CLI_MODEL_OK` и Python gate `NATIVE_GATE_RC=0`. _7 требует `php85-posix` из `sysutils/php85-posix` как реальную pkg dependency и проверяет её в CI. PHP root-проверка остаётся fail-closed. [CI #39053386699](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39053386699) PASS (Voice/Project/FreeBSD pkg dependency and ABI). [Testing prerelease](https://github.com/Tolian82/os-zapret2-restyle/releases/download/v0.5.3_7/os-zapret2-restyle-0.5.3_7.pkg) SHA256 `38f656a4e295f7451b1dd192737dba41d8e2f4405929fa81aa3b324a49158913` опубликован из исходника `e402d89`, build/publish workflow #39054050579, PR #346 создан через connector после запрета Actions createPR. Установленный PHP FD9 и Apply ещё требуют отдельного подтверждения.

### v0.5.3_8: OPNsense package compatibility correction

Owner confirmed php85-posix cannot be installed from OPNsense's repositories; _7 required a FreeBSD ports package in error. _8 removes the dependency, uses base /usr/bin/id -u via PHP proc_open(argv) without shell, strict output/status and retains FD9/inode/flock attestation. php -n test proves behavior without POSIX; FreeBSD pkg manifest now forbids php85-posix. No live Apply or call success claimed.

### v0.5.3_9: bounded pre-runtime Apply refusal

На установленной `_8` владелец подтвердил PHP FD9, native gate и CLI saved-model, но два GUI `shared-apply-run voice` завершились rc69 до появления native shared-work/journal. Точный отказ остаётся нераскрытым. `_9` возвращает строго ограниченную стадию отказа (`preflight-rejected`) только до запуска runtime/Config/IPFW, позволяя GUI отличить безопасный отказ подготовки от неопределённого исхода последующей транзакции. Общая архитектура и стабильный `v0.5.3_2` не изменяются; установленный Apply, STUN и звонки ещё не приняты.

### v0.5.3_10: Voice inherits Strategies WAN

Владелец установил `_9`, реальный GUI Apply Telegram ON показал `preflight-rejected=candidate`; Config/Voice-IPFW остались OFF, общая служба запущена. Приёмка установленного Apply/STUN/CALL остаётся открытой; не доказано, что ошибка `candidate` была вызвана WAN.
