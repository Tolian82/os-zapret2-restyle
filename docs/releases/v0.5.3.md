# os-zapret2-restyle v0.5.3

**Статус: исправление прошло проверку исходников и FreeBSD 15 `.pkg`, релиз подготовлен к публикации, но ещё не опубликован.** `PLUGIN_REVISION=2`, candidate `v0.5.3_2`; package candidate `os-zapret2-restyle-0.5.3_2.pkg`.

## Цель исправляющей поставки

Устранить подтверждённый отказ открытия Voice Transmission в опубликованном `0.5.2_194`: URL `/ui/zapret/voice` не имеет соответствующего UI-контроллера. Сохранить полное ТЗ, пять сервисов и общий backend со «Стратегиями». Поставка через существующий GUI/pkg-репозиторий одобрена владельцем как шаг [плана](../architecture/VOICE_TRANSMISSION_COMPLETION_PLAN.md).

## Граница готовности

В `_1` записаны правила наблюдаемого результата и план. В `_2` добавлен штатный UI VoiceController, устранён несоответствующий маршрут в IndexController, исправлен устаревший GUI тест и добавлена проверка настоящим Router OPNsense 26.7 для исходников/извлечённого `.pkg`. Исходники и извлечённый FreeBSD 15 пакет проверены в [CI #39023792241](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39023792241): Voice, Project и package завершились успешно. Источник `_2` интегрирован в `main` коммитом [`92a96ae`](https://github.com/Tolian82/os-zapret2-restyle/commit/92a96ae26235d5c3bad8492a00b2b60563722779). Текущий документационный коммит готовит явную полную публикацию `v0.5.3`; тег, GitHub Release, checksum и GUI/pkg-репозиторий необходимо подтвердить после выполнения release workflow. Установка исправления ещё не проверена. Доступность страницы, сохранение/Apply/boot и голосовая связь принимаются раздельно по [контролю приёмки](../VOICE_CODE_COMPLETION_GATE.md).

До фактического открытия установленной страницы: **исправление подготовлено; работа установленной страницы не подтверждена**. Эта фраза означает подтверждённый CI-результат исходников/пакета, но не открытую и отрисованную страницу в установленном OPNsense.
