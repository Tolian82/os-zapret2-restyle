# os-zapret2-restyle v0.5.3

**Статус: полный исправляющий релиз `v0.5.3` опубликован 17.10.2026.** `PLUGIN_REVISION=2`, candidate `v0.5.3_2`; package candidate `os-zapret2-restyle-0.5.3_2.pkg`.

## Цель исправляющей поставки

Устранить подтверждённый отказ открытия Voice Transmission в опубликованном `0.5.2_194`: URL `/ui/zapret/voice` не имеет соответствующего UI-контроллера. Сохранить полное ТЗ, пять сервисов и общий backend со «Стратегиями». Поставка через существующий GUI/pkg-репозиторий одобрена владельцем как шаг [плана](../architecture/VOICE_TRANSMISSION_COMPLETION_PLAN.md).

## Граница готовности

В `_1` записаны правила наблюдаемого результата и план. В `_2` добавлен штатный UI VoiceController, устранён несоответствующий маршрут в IndexController, исправлен устаревший GUI тест и добавлена проверка настоящим Router OPNsense 26.7 для исходников/извлечённого `.pkg`. Исходники и извлечённый FreeBSD 15 пакет проверены в [CI #39023792241](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39023792241): Voice, Project и package завершились успешно. Источник `_2` интегрирован в `main` коммитом [`92a96ae`](https://github.com/Tolian82/os-zapret2-restyle/commit/92a96ae26235d5c3bad8492a00b2b60563722779). Публикация подтверждена: тег `v0.5.3` указывает на точный release-preparation merge `376616af`, [GitHub Release](https://github.com/Tolian82/os-zapret2-restyle/releases/tag/v0.5.3) содержит пакет `os-zapret2-restyle-0.5.3_2.pkg` и `SHA256SUMS`, [workflow #39024503035](https://github.com/Tolian82/os-zapret2-restyle/actions/runs/39024503035) успешно создал FreeBSD:15:amd64 pkg repository и опубликовал GitHub Pages. [Детали](../verification/evidence/2026-10-17-v0.5.3-release-publication.md). Установка исправления ещё не проверена. Доступность страницы, сохранение/Apply/boot и голосовая связь принимаются раздельно по [контролю приёмки](../VOICE_CODE_COMPLETION_GATE.md).
