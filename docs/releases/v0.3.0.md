# os-zapret2-restyle v0.3.0

Release date: 2026-08-03
Package: `os-zapret2-restyle-0.3.0_1.pkg`
Target: OPNsense 26.7 / FreeBSD 15 amd64

## Headline

v0.3.0 delivers the live-verified **Zapret2 Service** control surface for OPNsense.
Users can see runtime health and the active bol-van/zapret2 tag, start or stop the
service, browse stable upstream releases, and install, reinstall, upgrade, or downgrade
without rebooting the firewall.

## Highlights

- Native collapsible Zapret2 Service block on the Settings page.
- Started, Stopped, Error, installed release, setup state, and busy-state reporting.
- Start/Stop control with complete runtime-state checks.
- Four latest stable upstream releases in the GUI.
- Validated release cache with locked refresh, atomic replacement, and stale fallback.
- Exact stable-release installation through the existing setup.sh backend.
- Transactional active-release publication and automatic rollback.
- Runtime-safe `0644` Lua/blob permissions after dvtws2 drops privileges.
- Automatic `ipdivert` and `ipfw` preparation before cold-start launch.
- Started/Stopped preservation through plugin replacement and runtime release changes.
- Existing configd watcher preserved during package replacement.

## Live verification

Verified on OPNsense:

- cold reboot automatically started Zapret with required kernel modules and rule 19000;
- `pkg add -f` over Started returned to Started with replacement PIDs;
- `pkg add -f` over Stopped remained Stopped;
- release-cache mtime remained unchanged on a repeated fresh read;
- Stopped v1.0.3 → v1.0.4 remained Stopped;
- Started v1.0.4 → v1.0.3 finished Started;
- Git HEAD and `/var/db/zapret2-restyle/runtime.release` matched the selected release;
- Lua files remained `0644 root:wheel`;
- no reboot, manual configd restart, Web GUI restart, or manual Zapret restart was
  required after successful managed operations.

## Installation and update

Register the project repository once:

```sh
fetch -o /usr/local/etc/pkg/repos/zapret2-restyle.conf \
  https://tolian82.github.io/os-zapret2-restyle/zapret2-restyle.conf
pkg update -f
```

Then install or update through **System → Firmware → Plugins**.

Package replacement preserves the pre-existing service state. A running service is
restored before pkg completes; a stopped service remains stopped.

## Runtime selection

Open the Settings page, expand **Zapret2 Service**, choose a stable upstream release,
and click **Apply**.

The GUI operation uses:

```text
setup_launcher.sh
    → setup_transaction.sh
    → setup.sh
    → zapret_service.sh
```

The selected release is published as active only after successful build and service
activation.
