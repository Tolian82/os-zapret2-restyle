# 2026-08-07 — v0.3.3_10 serialized worker state transitions

## Scope

Patch 5 of the third-audit corrective series implements `SL3-004`.

## Root cause

`worker_skip_unfinished()` replaced `status.json` through its own read/jq/temp/mv sequence. Cancel and finalization use `strategy_lab_state_transform()`, so the private worker write could race with a newer cancel transition, overwrite cancellation evidence, and avoid the monotonic revision contract.

## Implementation

- Replaced the private worker skip writer with `strategy_lab_state_transform()`.
- The canonical per-job state lock, atomic replacement, and `.revision` increment now cover unfinished-stage skipping as well as API cancel and worker finalization.
- No new locking primitive or secondary state writer was introduced.

## Regression coverage

`test-strategy-lab-state-race.sh` now:

- races cancel against `worker_skip_unfinished()`;
- races a repeated cancel against another skip transition;
- verifies `cancel_requested=true` and the original `cancel_requested_at` survive;
- verifies stages 90 and 99 are not skipped;
- verifies monotonic revisions across every state mutation;
- verifies terminal state remains irreversible;
- rejects reintroduction of the old `.worker-skip.*` private writer.
