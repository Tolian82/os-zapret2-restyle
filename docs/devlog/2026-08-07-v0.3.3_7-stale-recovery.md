# 2026-08-07 — v0.3.3_7 ordinary stale recovery correction

## Scope

Patch 2 of the approved third-audit corrective series closes the source scope for `SL3-001` and `SL3-005`.

## Root cause

Ordinary stale-worker reconciliation had a second restoration implementation in `strategy_lab/launch.sh`. It treated public `status/start/stop` exit codes as sufficient proof and could write `restoration.verified=true` while also writing `strategy_unchanged=false`. In addition, stale reconciliation runs synchronously from start/status/cancel/result while the outer configd, MVC, and browser waits were only 10/10/15 seconds, shorter than the legitimate bounded stage-90 restoration transaction.

## Implementation

- Added executable `strategy_lab_recovery_worker.sh`.
- Added service action `strategy-lab-recover` to `zapret_service.sh` and routed it through `service_with_lifecycle_lock` plus `run_strategy_lab_worker`, which exports the lifecycle owner environment before executing the recovery worker.
- The recovery worker loads the persisted lifecycle snapshot and calls the existing semantic `strategy_lab_restore_initial_service_state()` implementation.
- Removed the launcher's public status/start/stop restoration shortcut.
- The launcher now accepts stale restoration only when persisted evidence proves verified restoration, unchanged strategy evidence, clean temporary runtime, and exact initial/final service-state equality.
- A failed or inconsistent proof forces terminal `RESTORE_FAILED` and clears the verified flag instead of allowing retention to treat contradictory evidence as verified.
- Ordinary Strategy Lab configd actions now use 180 seconds, MVC uses 190 seconds, and browser AJAX uses 200 seconds. Normal asynchronous worker search budgets remain 150/270 seconds; these values only bound synchronous control/recovery responses.

## Regression coverage

- `test-strategy-lab-stale-worker-recovery.sh` now exercises verified, inconsistent, and failed persisted recovery evidence and rejects any launcher fallback to public lifecycle commands.
- `test-strategy-lab-stale-recovery-contract.sh` asserts lifecycle-owned service routing, reuse of semantic restoration, removal of obsolete shortcut helpers, and monotonic 180 < 190 < 200 second outer timeouts.
- Existing semantic restoration, e2e, retention, and corrective-matrix tests remain mandatory.
