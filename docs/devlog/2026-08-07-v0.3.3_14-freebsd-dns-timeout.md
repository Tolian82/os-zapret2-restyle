# 2026-08-07 — v0.3.3_14 FreeBSD Strategy Lab DNS timeout correction

## Scope

One logical live defect: stage 40 reports mandatory endpoint DNS failure on FreeBSD even though the resolver returns the target immediately outside the Strategy Lab timeout wrapper.

The separate `target_type:"A"` shell-variable namespace defect and the previously identified stage-50 family-runner defect are intentionally excluded.

## Live evidence

Owner-assisted Scenario 1 on `os-zapret2-restyle-0.3.3_13.pkg`, job `job.3mc9c6`, passed stages 00–30 and failed stage 40. Stage 90 passed, proving the `_13` restoration correction on the appliance.

For `rutracker.org`:

- `/usr/bin/drill rutracker.org A` returned `rc=0`, `NOERROR`, and two A records in 96 ms;
- `/usr/bin/timeout 2 /usr/bin/drill rutracker.org A` returned `rc=124` after exactly two seconds with zero output;
- `/usr/bin/timeout -f 2 /usr/bin/drill rutracker.org A` returned `rc=0`, `NOERROR`, and the same A records in 30 ms;
- a `yandex.ru` control query through the non-foreground timeout wrapper returned `rc=0`.

Evidence: `docs/verification/evidence/2026-08-07-v0.3.3_13-scenario-01-stage40-freebsd-dns-timeout.md`.

## Root cause

`strategy_lab_dns_request()` wraps `drill` with FreeBSD `timeout(1)` without foreground mode. On the live appliance this exact wrapper returns 124 with no output for the blocked-domain target even though `drill` itself completes in tens of milliseconds. The identical command with `timeout -f` succeeds immediately.

Stage 40 then interprets the wrapper failure as endpoint DNS failure and aborts the search before candidate testing.

## Correction

`strategy_lab_dns_request()` now detects the platform using `/usr/bin/uname`. On FreeBSD only, the DNS request uses `timeout -f 2`; non-FreeBSD systems retain the existing `timeout 2` behavior.

A focused regression requires the FreeBSD call shape to contain `-f` and the Linux call shape to omit it. The regression is automatically included by the mandatory Strategy Lab corrective matrix.

`PLUGIN_REVISION` advances from 13 to 14.
