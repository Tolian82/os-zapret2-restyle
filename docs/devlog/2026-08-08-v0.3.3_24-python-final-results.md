- `strategy_lab_profile_replay_runner.sh`;
- `strategy_lab/worker_result.sh`;
- `strategy_lab/worker_stage_machine.sh`.

Private circular remains intentionally shell-owned and still uses its independent candidate
consumer/session state. Audited FreeBSD mutation helpers remain shell adapters.
