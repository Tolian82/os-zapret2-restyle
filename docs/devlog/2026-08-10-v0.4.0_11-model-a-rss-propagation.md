# 2026-08-10 — v0.4.0_11 Model A RSS propagation correction

## Trigger

The first owner appliance Model A summary on `v0.4.0_10` used Standard
`rutracker.org` job `job.Oeq7Rc`. The job itself completed `SUCCESS` with verified clean
restoration and produced 25 usable cold candidate samples.

The summarizer returned `inconclusive` for exactly one missing coverage check:
`rss_observed=false`.

## Diagnosis

The FreeBSD candidate adapter was already correct. Its runtime `snapshot` action validates
the candidate PID and emits a numeric `rss_kb` value from `ps` when available.

The loss happened in Python `_readiness()`: it reconstructed a readiness dictionary from
the adapter snapshot but omitted `rss_kb`. That dictionary was then written to
`candidate-runtime/readiness.json` and embedded as each candidate result's `runtime`
evidence. The Model A summarizer therefore saw only null RSS values even though the shell
adapter had measured them.

## Correction

The Python readiness evidence now copies `snapshot.get("rss_kb")` into the persisted
runtime object. The no-snapshot fallback explicitly uses `rss_kb=None`.

The candidate/family regression fixture now returns `rss_kb=12345` from its mock adapter
and requires the final persisted candidate result to retain exactly `12345`.

No Model A scoring/coverage rule changed. No search ordering, candidate lifecycle,
timeout, restoration, interception or validation behavior changed.

## Live baseline retained

The `_10` report already provides a useful cold timing baseline across 25 samples:

- total candidate median 1556 ms, p90 3403 ms;
- readiness median 1046 ms, p90 1054 ms;
- combined prepare median 140 ms, p90 155 ms;
- launch median 17 ms, p90 20 ms;
- probe median 208 ms, p90 2056 ms;
- stop + cleanup median 78 ms, p90 85 ms.

It also covered PASS/FAIL, repeated candidates, all required resource classes, `-d8`, 16
unique overlapping TLS/443 specs and verified restoration. RSS alone prevented
`reference_collected`.

## Handoff

After CI, FreeBSD 15 package qualification and testing-prerelease publication, one
comparable Standard `rutracker.org` run on `v0.4.0_11` should be summarized with the
existing Model A command. A numeric RSS observation plus the already exercised coverage
conditions should close the cold-reference collection gate.

Model B/C remain experimental until this corrected Model A reference is collected and
reviewed.
