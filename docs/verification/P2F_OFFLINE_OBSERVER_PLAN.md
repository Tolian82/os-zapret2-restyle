# #1052 P2f — original-builder trailing observer proposal (nonactivating)

**Source candidate:** `v0.6.5_16`. This is a bounded preparatory P2f change, **not an operational Auto-detect collector**. P0/P1 and the native P2e original-builder qualification remain closed in their documented scopes.

## Observable source result

The existing `orchestrator_build_release()` for a disposable shared `auto` candidate emits the genuine nonactivating schema-1 `auto-detect-source-map.json`. The new `auto_detect_origin_map.plan_trailing_observer()` consumes that artifact and the **exact same-build original `dvtws.args` bytes**, plus explicitly supplied owner identity, candidate digest, observation paths and scoped TCP ports. It returns an in-memory proposed argv and map, rather than editing the original sealed candidate.

The proposed argv places one native `--hostlist-auto-debug` flag in the preamble and appends the P0-proven final **no Lua, no import, no IPSET, no payload** observer: `--new`, TCP filter, `http,tls` L7 filter, dedicated `--hostlist-auto` raw inbox, fail threshold and `--hostlist-auto-retrans-reset=0`. Earlier actual profiles retain their order. The proposed map records existing profile statuses/source HOSTLISTs, the implicit native profile 0 and a new observer number. Mixed HOSTLIST+IPSET, Voice/STUN and untrusted origin never become known HOSTLISTs.

The planner refuses an absent/stale original generation, changed original argv digest, incorrect candidate identity, an existing auto observer, duplicate/nonsequential native numbers, an unexpected HOSTLIST label, unsupported TCP ports or observation paths. The paths used in the offline contract are **not** a claim of qualified installed permissions or native file provisioning.

**Important authorization boundary:** the output marker is `P2F_OFFLINE_PLAN_ONLY`. It deliberately **fails** the production `auto_detect_owner._valid_map()` requirement `ORIGINAL_SHARED_GENERATOR_CAPTURE`. No `auto-detect-generation.json` is emitted, no running owner is attested, no input/debug files are created, no traffic is captured, and no cron, pending acknowledgement, auto-owned destination write or new `dvtws2` is enabled.
