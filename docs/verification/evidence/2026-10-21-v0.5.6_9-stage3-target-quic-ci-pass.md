## Source changes in the actual runtime

- Replaced target `openssl s_client -quic` process-exit evidence with private Chrome `--http3-only` pinned `--resolve` to actual target IPv4, Host/SNI, and CA; HTTP/2/TCP fallback is disallowed.
- The shared `chrome_quic_evidence` classifier requires the actual executed `--http3-only` command, observed `remote_ip` equal to epoch-selected IP, certificate verification zero, and either a completed QUIC/TLS handshake (positive `time_appconnect`) **OR** a genuine final HTTP/3 2xx–5xx response. An HTTP/3 response body is not required.
- Both original candidate and IP-target/Host-SNI override now use returned remote IPv4, not the selected address copied into `remote_ip`. Candidate success additionally requires IPFW UDP/443 packet-count growth, unchanged endpoint matching and intact runtime cleanup.
- The Python Extended QUIC handler performs an authenticated direct-target check **before QUIC candidate execution**, separately from unrelated Stage30 control-host reachability. If all mandatory targets are directly reachable over QUIC, result is `direct_accessible`; orchestrator returns `TARGET_ACCESSIBLE`, skips Stage85 and uses existing Stage90 semantic restoration. This direct check occurs after Stage20 stop; Stage80's Extended TCP branch may have executed before the QUIC branch.
- Otherwise each QUIC catalog candidate runs up to three independent candidate executions. Only actual 3/3 passes set `working`. A first failed attempt terminates that candidate early. A claimed finalist still undergoes existing exact Stage85 profile replay and remains subject to its strict verification. Four-candidate catalog limit unchanged.
- Runtime/FD9/Stage90, Standard Chrome and Model C search implementation untouched.

## Controlled negative/positive tests

`scripts/test-strategy-lab-quic-target-proof.sh` calls the real QUIC request/parser, both real candidate probes and Extended Stage80 handler with mocked transport/counters. Positive tests cover TLS handshake without HTTP, HTTP/3 503 without positive handshake time, direct QUIC early termination, candidate 3/3 and IPFW interception.
