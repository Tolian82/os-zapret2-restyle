## New read-only/native synthetic experiment

The [Stage 0 sidecar runner](../../../scripts/stage0-opnsense-pkg-sidecar-bypass.py) runs only on a disposable OPNsense 26.7 KVM, verifies `FreeBSD:15:amd64` and initially absent real plugin, then installs the **exact immutable published original `0.6.2_1.pkg`** into the normal isolated guest's real native pkgdb using the qualified original-install helper. It re-verifies actual original package SHA, installed native service bytes/mode/owner and four hooks. It never replaces/removes this real predecessor or calls its Stop, Start, Apply, configd, IPFW or Python migration.

The fixture package uses **another package name**, `zapret2-stage0-sidecar-only-fixture`, exclusively with a private `PKG_DBDIR`, cache and payload in a temporary directory. First, install inert original synthetic fixture `0.6.2_1`. Parent acquires a **separate private sidecar guard** using FreeBSD flock(2), proving a separate `lockf -s -t 0 9` process cannot acquire it. The authentic old installed Zapret2 service Status then independently obtains its **different FD9**, returns rc=1 and exact `zapret is not running` without blocking. Next call real native `pkg add -f` of synthetic `0.6.2_40`: its incoming PRE_INSTALL and POST_INSTALL are instrumented to execute the **genuine original installed old service Status**, each demanding STOPPED and exit 0. They must both be observed in the actual hook trace, and private pkgdb/payload must become `0.6.2_40`. This demonstrates **lock compatibility only**, not a supported pkg entrypoint or transaction atomicity.

**Critical negative:** Without releasing the parent sidecar lock, a **direct uncoordinated native `pkg add -f`** installs a third synthetic `0.6.2_41` package. Confirm the independent contender still cannot acquire the guard, while native pkg nonetheless replaces the synthetic fixture, proving the sidecar lock is **not enforced by arbitrary native pkg invocations**. Then release the guard, verify native contender can acquire it, and re-verify the real installed original package/service provenance and true STOPPED. All changes are isolated to disposable guest and synthetic private package data.
