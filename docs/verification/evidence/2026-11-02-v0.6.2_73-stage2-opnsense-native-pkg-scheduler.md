# v0.6.2_73 — Stage 2.23 OPNsense native pkg scheduler fixture

**Scope:** source/CI-only qualification in a **disposable** OPNsense 26.7 FreeBSD 15 amd64 guest. Stable published `0.6.2_1.pkg` remains immutable and the owner appliance is never contacted. `0.6.2_73.pkg` is **not published**.

## Question

Stage 0 observed on a standalone FreeBSD 15.1 VM that a real `pkg add -f` replacement can skip old package `pre-deinstall` and `post-deinstall` scripts entirely. Verify whether the **actual OPNsense target pkg scheduler** exhibits the same order before assuming an old deinstall hook will protect package replacement.

## Exact test path

`.github/workflows/stage2-real-native-running-upgrade.yml` runs the unchanged `scripts/stage0-real-pkg-scheduler.py` **inside the same real isolated OPNsense 26.7 guest**, against the SHA-verified immutable archived `0.6.2_1.pkg`. The scheduler creates only temporary synthetic tracer packages named `zapret2-stage0-phase-order-fixture`, with an isolated temporary `PKG_DBDIR`, payload and phase log. It then runs real `pkg add`, real `pkg add -f`, and a real explicit `pkg delete` against the fixture.

Required observed fixture order: `old:pre-install`, `old:post-install`, `new:pre-install`, `new:post-install`, then explicit deletion `new:pre-deinstall` and `new:post-deinstall`. The host-run fast contract `scripts/test-stage0-real-pkg-scheduler.py -v` must PASS before starting the VM. The guest asserts the exact JSON fields and emits `STAGE2_OPNSENSE_PKG_SCHEDULER`.

**Important proof boundary:** fixture scripts are deliberately **not** archived old or new production hook bodies. A fixture PASS only proves the native OPNsense `pkg` scheduler behavior. The existing real old RUNNING → native successor test subsequently runs real production package hooks and proves its end-state, but it **does not** trace every original hook phase, hold a root-pkg-wide FD9 lock, or prove fail-closed replacement under unknown/foreign IPFW process ownership. Those requirements are still **OPEN** under Stage 2.23 / Stage 3.24.
