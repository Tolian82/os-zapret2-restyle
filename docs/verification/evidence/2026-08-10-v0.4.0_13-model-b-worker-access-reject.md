## Source/live correlation and root cause

The Model B worker wrapper creates the session tree under:

`/var/run/zapret2-restyle/strategy-lab/model-b/session.<pid>/workers/...`

and `_13` explicitly changes both the persistent Model B root and per-run session directory
to mode `0700`. Every selected Model B candidate is hostlist-backed and is launched with
`--user=nobody`; its hostlist is nested below those private ancestors.

This reproduces a previously owner-proven FreeBSD dvtws2 boundary from
`v0.3.3_16`: dvtws2 initially loads the hostlist, drops to UID/GID 65534, then performs a
post-drop reopen/access check. A mode-0644 hostlist remains inaccessible when any parent
directory lacks search permission. The historical `_16` evidence recorded the exact
`file_open_test: Permission denied` / `cannot access hostlist file` failure and led to the
normal Strategy Lab bounded 0711 traversal lease.

The `_13` report does not retain per-worker dvtws2 logs after session cleanup, so it does
not itself contain that literal error text. The deterministic source condition, the exact
previous live behavior, and the `_13` null PID/socket/RSS snapshots identify the missing
post-drop traversal lease as the current startup blocker.

Historical authority:
`docs/verification/evidence/2026-08-07-v0.3.3_16-scenario-01-stage50-hostlist-access.md`.

## Corrective scope for v0.4.0_14

`_14` reuses the already owner-proven bounded-access design rather than changing Model B
architecture:

1. keep the Model B root and active session non-listable but searchable (`0711`) only while
   the experiment-owned warm workers are alive;
2. keep worker directories traversable and hostlists read-only;
3. restore the retained Model B root to private `0700` on every worker-wrapper exit path;
4. preserve lifecycle-lock ownership, dedicated ports/rules, sequential probing and exact
   semantic restoration;
5. add regression assertions for the access lease and its private-mode restoration.

No warm-worker production approval, parallel probing, Model C, dispatcher redesign,
strategy-search behavior or normal Strategy Lab candidate lifecycle is changed.

## Separate confirmed diagnostic/control defect

The `_13` run also proves that Model B currently continues into route/probe and controlled
stop/death steps even when `all_workers_ready=false`. That produces avoidable network
timeouts and lets the later `kill-owned` error obscure the earlier readiness failure.

This is retained as a separate follow-up correctness item so `_14` remains one logical
live-proven worker-access correction. Model B cannot be production-approved while that
fail-fast boundary remains unresolved, even if the `_14` access rerun otherwise advances.
