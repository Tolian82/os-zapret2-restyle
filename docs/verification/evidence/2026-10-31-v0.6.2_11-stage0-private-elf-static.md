# Stage 0 / I-00 — static private ELF dependency proof from released packages

**Scope:** source/static-only signed historical archive evidence; not the qualified target runtime. TЗ and plan independent editorial revisions remain v1.2.

## Exact inputs and immutable provenance

- Published installed-version predecessor archive `0.6.1_30.pkg` SHA-256 `f14be8fa63ee51dfd3fa9c3bbdcb340bde2945fddff61bd278aa54a87d97826d`; published stable archive `0.6.2_1.pkg` SHA-256 `1e21fbcac847529b94fea940241b4da7f86a42d33c129b7003ad04a72f4e5a0f`. Neither archive is automatically equal to installed bytes.
- Both published packages contain a private `curl-impersonate` ELF, SHA-256 `e4af7ba05b6ad8dd997aefeae3a9c15a08be2700534d043cd93c7987f97c451f`, already verified by the published-package inspection. The new inspector checks this inner digest **and** each different outer archive digest before reading.
- `scripts/stage0-private-elf-audit.py` reads the file *from the tar archive*, extracts it only to a temporary file inside the disposable CI runner, uses `readelf -W -h -l -d` to record the static machine, OS/ABI header, loader/interpreter, requested `DT_NEEDED` sonames and RPATH/RUNPATH, then deletes the temporary file. The binary is never executed, loaded or included in uploaded evidence artifacts.
- Unit tests use a FreeBSD-style dynamic-tag fixture and a real host ELF in an isolated synthetic tar archive, testing parser fields and negative outer/inner digest refusal. The exact CI job uploads machine-readable JSON for both published archive inputs.

## Limits and next gate

Static ELF dependencies identify **required library names**, not the packages, versions or ABI-compatible implementations installed by qualified **OPNsense 26.7** repositories. Inspect the actual package providers, resolved loader/sonames and independent old FreeBSD.conf/backup ownership on an authorized OPNsense target before Stage 0 closure. Neither CI running a Linux `readelf` nor existing stock FreeBSD15 build tests are installed target acceptance; Stage 1 STOP gate remains active. No installed state, service, Config, IPFW, or stable asset is modified.
