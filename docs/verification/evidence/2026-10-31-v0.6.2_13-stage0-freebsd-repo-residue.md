**Scope:** read-only existing-source analysis and isolated filesystem fixtures; no owner host accessed, no production setup lifecycle mutation, no release publication. The independently versioned TЗ and plan remain v1.2.

## Exact legacy code audit

- `src/opnsense/scripts/OPNsense/Zapret/setup.sh:18–19` declares `/usr/local/etc/pkg/repos/FreeBSD.conf` and `${STATE_DIR}/FreeBSD.conf.backup` (normally `/var/db/zapret2-restyle/FreeBSD.conf.backup`).

The original selection check is a grep for `enabled: no`, not proof of file provenance.
- `setup.sh:62–70` and `:72–90` repeat blind backup-overwrite in the finish trap when `ENABLED_FREEBSD_REPO=1`. Merely confirming presence, hashes, similar content or an old setup.status marker does not exclude a human or another program having edited the repository file.
- `setup.sh:383–396` calls temporary stock repository enablement, `pkg update`, installs `pkgconf`, `luajit`, `git-lite`/`git`, `jq`, and calls restoration. **This old system-repository mutation is not an authorized target provisioning path under TЗ v1.2.**

## Six offline fail-closed scenarios

| Shape / evidence | Read-only classification | Permitted change |
|---|---|---|
| No current file or backup | `no-residue` | None |
| Backup without current file, or current file without backup | `ambiguous-refuse` | None |
| Exact temporary legacy bytes plus nonempty disabled-backup candidate | `legacy-shape-candidate-requires-independent-ownership-proof` | None; current/backup preserved |
| Current file changed after old template, even with a backup | `foreign-or-edited-repo-refuse` | None |
| Empty, identical-to-temporary or missing disabled marker in backup | `invalid-or-ambiguous-backup-refuse` | None |
| Symlink, directory, oversized file, unreadable or changed-during-read | `unsafe-filesystem-object-refuse` or preserved unreadable category | None |

`scripts/stage0-legacy-repo-ownership.py` uses `lstat` plus no-follow file opening and bounded reads, reports only sanitized kind, length, digests and legacy-template/disabled-marker booleans, and sets `automatic_restore_allowed=false`, `ownership_verified=false`, `foreign_edits_excluded=false` for *every* classification. It never prints repository contents, calls `pkg`, writes to target paths, deletes a backup or enables a repository. Its optional `--json` only writes the caller-selected report destination; CLI default target paths are read-only and never exercised in CI.

`scripts/test-stage0-legacy-repo-ownership.py` executes six real temporary-directory cases plus internal variants (not just static source grep); CI tests interpreter compilation and fixtures independently in its existing Stage 0 source-audit job.

## Required independent proof for any future Stage 3 recovery

Before any real restore, establish that the plugin itself installed the **exact current temporary override**, that the saved original backup has authenticated continuity and exact original bytes, and that no foreign edit to either persisted file occurred since capture. Mere equality with the historical template or `cmp` hash match **does not meet the spec**; without independent ownership evidence automatic restore remains prohibited. Treat an unprovable old residue as **manual review/refusal**, not as permission to clobber current `/usr/local/etc/pkg/repos/FreeBSD.conf`.

The actual owner's OPNsense host has not run a probe; installed target product/pkg ABI, qualified package providers and real private ELF dynamic-link compatibility still block Stage 0 closure and Stage 1.
