## Reproducible witness

- Native `dvtws2 v1.0.6` compiled on FreeBSD 15.1 from exact pinned upstream Git SHA `221d7dff24bfec0cd5ac0a5070b8acef2008af3d`. No mock engine or installed router service.
- Candidate generator uses the **production** `global_exclusions.compose()` and `audit()` plus all six managed IPSET files and verified manifest; three executable `--new` profiles filter UDP ports **596**, **597**, **598**. No exclusion in baseline; exactly **one** `--ipset-exclude` per executable profile in excluded candidate.
- Each `127.0.0.1` and `::1` target is tested on each of the three ports, with **identical synthetic UDP payloads** across the two phases: **6 baseline + 6 excluded** packet cases. A transport check first proves transparent loopback delivery without divert.
- Native IPFW rule `19005` diverts only outgoing UDP 596–598 on `lo0` to local divert port `9989`. The test-only Lua callback unconditionally returns `VERDICT_DROP`: unexcluded packets must be dropped, while destination-address excluded packets must arrive with **exact original payload**. A separate UDP/610 flow must not be captured.
- The harness refuses execution without opt-in, root in FreeBSD 15.1, exact default-allow IPFW baseline and absence of an OPNsense filesystem. It requires exact owned rule readback, cleanup between phases and kernel rule restoration; any unexpected state is FAIL, not SKIP.
