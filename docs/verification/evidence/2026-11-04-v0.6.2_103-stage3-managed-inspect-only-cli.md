## Observable command and admission boundary

New installed-source `src/opnsense/scripts/OPNsense/Zapret/backend/native_pkg_managed.py` provides **only** `inspect-candidate ABSOLUTE_NATIVE_PKG_PATH EXPECTED_VERSION EXPECTED_SHA256`. It is invoked through the current target's Python provider, not as an executable shell script or a version-pinned interpreter. No `upgrade`, `reinstall`, `remove`, raw `pkg` or product-mutating subcommand exists: every non-inspection request returns **78 / `UPGRADE_NOT_IMPLEMENTED_NO_PKG`**. A successful inspection is explicitly **not transaction authorization**.

The root-only FreeBSD/amd64 launcher opens the historical `/var/run/zapret2-lifecycle.lock` without truncation or symlinks, validates root-owned exclusive inode and independent lock challenger, and fails if busy. It launches a separate-session child with only a private AF_UNIX socket descriptor inherited. One exact random per-call head/nonce is sent through that socket together with the **original held lock** via `SCM_RIGHTS`, using the shared `_101` packaged receiver. The child verifies unchanged root-owned source digest and parent PID, duplicates the received original lock to FD9, and uses the `_102` candidate gate to recheck package identity and original FD9. The parent checks the worker's actual PID, nonce, lock inode, candidate SHA and nonmutating result, then releases its FD. A socket descriptor originally numbered 9 is moved before child launch. All subprocesses and socket operations have bounded waits; failed or missing verdicts refuse.

**Proof ceiling:** This is an actual packaged *diagnostic CLI source path*, not an installed or accepted **upgrade**. It does NOT check historical RUNNING/STOPPED process/IPFW/Config ownership and MUST report `old_owner_qualified=false`, `pkg_invoked=false`, `lh08_ac11_accepted=false`. No hook mutation, no firmware/Web integration, and no claim against direct root pkg bypass.
