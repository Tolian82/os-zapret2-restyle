## Gap and deliberately bounded scope

_113 requires a detached RSA-SHA256 signature on the root-private exact manual `operator-pins.json`, checked using a separately SHA-pinned operator approval PEM. However an old *valid* signature could be replayed indefinitely, and its claimed approval has no time window or explicit recorded revocations. A private mode, a signature, or checking an expiry against the local clock alone does not solve distributed replay, revocation freshness, or signer identity.

_114 adds a **mandatory second, byte-exact, detached RSA-SHA256-signed approval-policy snapshot** with a separately supplied 64-lowercase-hex **expected SHA-256 of the whole snapshot**. This snapshot has an explicit maximum **3600-second authorization window** and two bounded deny lists. It is verified **before** any external Python verifier is loaded or executed. This is a **fail-closed read-only scope and freshness check**, NOT a production one-time upgrade token or a proven anti-rollback system.

**Illustrative security test interface only, never a production upgrader.** No owner approved the policy SHA, authority, seed bytes, crypto identity or executable source. Both SHA arguments are **caller-supplied** and must obtain actual independence from a real owner-approved external channel; a matching self-published hash is not security.

The strict snapshot schema (`zapret2-prepkg-approval-policy-v1`) has **exactly** the following JSON keys, without duplicate keys or unknown attributes:

| Attribute | Strict meaning |
|---|---|
| `schema`, `repository` | Immutable expected schema and `Tolian82/os-zapret2-restyle` |
| `authority_sha256` | Exact independent operator-approval PEM fingerprint, matches `--operator-authority` |
| `receipt_sha256` | SHA-256 of the **exact byte stream** of the first previously RSA-signed `operator-pins.json` (no re-encoding) |
| `sequence` | Strict positive JSON integer, preparatory monotonic marker; **not** enforced against persistent history |
| `issued_at`, `not_before`, `not_after` | Strict non-negative Unix seconds integers (bool is rejected), `not_before <= issued_at <= not_after`, `0 < not_after-not_before <= 3600`, local host time in interval and at/after issue |
| `revoked_receipt_sha256` | Bounded maximum 32 unique exact lowercase 64-hex receipt digests; matching current receipt **refused** |
| `revoked_authority_sha256` | Bounded maximum 32 unique exact lowercase 64-hex authority PEM digests; matching current authority **refused** |

Three captured root-owned, single-linked private files (`operator-pins.json`, `operator-approval-policy.json`, `operator-approval-policy.sig`) plus operator authority key and receipt signature are all checked for canonical root path, `0700` parent, `0600` file, `O_NOFOLLOW`, stable FD inode/size/ctime/mtime and size cap. First the **existing signed receipt** must pass. The approval policy bytes must then match their separately expected SHA, pass a second real RSA detached signature with the independently pinned operator-approval PEM, match exact receipt SHA and authority SHA, validate strict structure/window/denylists and reject any explicit matching revocation. Only then are receipt pins used to hash/freeze the external verifier; subsequently signed package provenance must match source commit, exact key, and both archive hashes, followed by original FD9 cold read-only native archive inspection.

The operational label is deliberately **`SIGNED_POLICY_TIME_AND_REVOCATION_MATCHED_NOT_ONE_USE`**. Neither reading a policy nor a positive timestamp test consumes a token. **No persistent anti-replay state, monotonic sequence store, external clock attestation or latest-snapshot oracle exists.** An old, still-valid signed snapshot and approval can be replayed within the window, and a revoked receipt can pass if a caller substitutes a correctly signed older, not-yet-expired policy plus its corresponding SHA and no external owner-approved digest check rejects the rollback. Clock skew/tampering can also invalidate the time assumption. Real key revocation must be managed out of band, not by the potentially revoked signer alone.
