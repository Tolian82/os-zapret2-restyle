# v0.4.1_20 — Laboratory frame and navigation owner-live follow-up

**Date:** 2026-08-15  
**Evidence class:** OWNER-LIVE VISUAL / UI NAVIGATION  
**Installed package:** `os-zapret2-restyle-0.4.1_20`

## Observation

The owner supplied direct screenshots of the installed `_20` package and compared the plugin pages with a native OPNsense page.

Observed on `Services: Zapret DPI Bypass: Laboratory`:

- the normal OPNsense outer content perimeter/frame is absent;
- Laboratory content runs against the page edge instead of using the same platform-owned inset as Strategy and ordinary OPNsense pages;
- while Laboratory is active and OPNsense language is Russian, the submenu labels are `Стратегия` / `Лаборатория`.

Observed after navigating to `Services: Zapret DPI Bypass: Strategy` with the same Russian OPNsense language:

- the normal OPNsense page perimeter is present;
- the submenu labels revert to the canonical English `Strategy` / `Laboratory`.

A native OPNsense settings page supplied in the same comparison confirms the expected platform perimeter/spacing.

## Confirmed root causes in `_20` source

- `diagnostics.volt` creates its own `page-content-main/container-fluid/row/column` wrapper and `_20` then globally neutralizes `.page-content-main` margins/padding. Because the selector also matches the platform-owned page wrapper, the normal OPNsense perimeter is removed rather than merely avoiding a second inset.
- Laboratory performs deterministic submenu RU/EN rewriting in its page JavaScript, but `general.volt` does not. A full navigation to Strategy therefore reloads the canonical English names from `Menu.xml` without reapplying Russian labels.

## Owner-selected correction

- restore the platform-owned OPNsense page perimeter and remove the redundant Laboratory page wrapper/override rather than styling the platform wrapper away;
- preserve the accepted common 25% Diagnostics field grid and mode-label typography behavior;
- apply deterministic `Стратегия` / `Лаборатория` versus `Strategy` / `Laboratory` navigation text on both plugin pages according to the active OPNsense HTML language;
- do not change Strategy Lab runtime/search semantics.

This evidence supersedes `_20` visual-acceptance-pending status for the perimeter/navigation rows: `_20` is rejected for those two visible UI behaviors and corrected forward in `_21`.
