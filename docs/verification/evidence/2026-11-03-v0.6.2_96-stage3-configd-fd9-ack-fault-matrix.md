## Fixed root-only fault cases

| Fault | Injection in actual native child | Correct outcome |
|---|---|---|
| `drop_ack` | Exact root-owned READY written under original received FD9, then genuine `os._exit(96)` **before ACK** | Configd command never qualifies admission; independent original FD9 becomes free; original package/Config/IPFW unchanged |
| `stall_ack` | Child writes READY, delays 17 seconds beyond launcher `recv` 15-second bound, then `os._exit(97)` | Bounded timeout; neither READY nor a delayed ACK means admission; FD9 released by kernel on exit |
| `post_ack_exit` | Child sends correct SHA/nonce/PID ACK, then `os._exit(98)` immediately | Even if `configctl` reports provisional ACK/success, **independent external original FD9 check MUST show no durable lock**, so the operation is refused before `pkg` |

The only fault selector is a **fixed allowlist**, requiring exact `ZAPRET2_STAGE3_HANDOFF_NEGATIVE=1`, previously required disposable root/native `GITHUB_ACTIONS=true` and exact SHA/old package checks. No user parameter or fallback generic action is exposed; one existing historical lock path is reused. `os._exit` tests actual kernel descriptor cleanup rather than a mocked exception.
