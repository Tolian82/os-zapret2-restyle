## Distinct proven versus missing guarantee

The existing `scripts/test-private-curl-native-ech.sh`, run after `scripts/build-pkg.sh` in an isolated FreeBSD 15.0 CI job, **already executes a freshly acquired/staged private curl candidate** with `--ech false` and loopback connection refusal. - In a fresh disposable **FreeBSD 15.1 amd64** GitHub Actions VM, `ldd` must resolve **all six known** `DT_NEEDED` sonames to real files, the extracted ELF must actually execute `-V` and advertise HTTPS/HTTP3, and a Chrome-profile `--ech false` invocation to `127.0.0.1:1` must fail **only** with connection refused/timeout (7/28). An independent `stage0_private_elf` path classifier triggers the new real VM job on changes to these tests, with the normal all-package-source CI also triggering it.
