# v0.4.1_9 Model-C lifecycle owner-live reject

Status: **REJECTED — MEASUREMENT ADAPTER WIRING DEFECT CONFIRMED**

Date: 2026-08-13

## Owner-live observation

Published package `os-zapret2-restyle-0.4.1_9.pkg` installed successfully and the retained
Rutracker lifecycle measurement was run with five requested repeats against `job.lWLjqL`.

The `_9` diagnostic corrective worked as intended: it left an inspectable report with
`conclusion=measurement_rejected`, `completed_repeat_count=1`, `fail_fast=true` and
`fallback_detected=true`.

The exact first-batch reason was:

`Model C unavailable (Stage-60 controlled source-port alternate pool is exhausted); Model B fallback failed (Stage-60 controlled source-port alternate pool is exhausted)`

Batch 1 contained `seqovl-host`, `multisplit-host` and `multidisorder-host`. The remaining
persisted batches used `A-cold-fallback`; no Model-C lifecycle samples were eligible for
cost/RSS summaries. Cold fallback completed all fourteen persisted batches in `45314 ms`,
with `seqovl-host` and `seqovl-midsld` as working candidates. `cleanup_ok=true` and
`lifecycle_restored=true`.

## Source diagnosis

Production `strategy_lab_stage60_parallel_runner.sh` exports
`STRATEGY_LAB_MODEL_B_SYSTEM_ADAPTER` pointing at
`strategy_lab_model_b_parallel_adapter.sh`. The parallel adapter provides both
`source-port-free` and `route-add-source`.

The lifecycle measurement worker instead defaulted to the base
`strategy_lab_model_b_adapter.sh` and did not export a production-equivalent adapter path
for its direct Python replay. The base adapter does not implement `source-port-free`.
Consequently every lease availability probe returned non-zero, so the bounded allocator
rejected the complete 2048-port alternate scan for both Model C and its fresh Model B
fallback.

The observed exhaustion is therefore a measurement-induced infrastructure failure, not
evidence that production Model C exhausted real TCP source ports. Production Stage-60
source-port leasing and adapters are unchanged by the required corrective.

## Required corrective

Make the lifecycle measurement owner select/export the same controlled-parallel system
adapter as the production Stage-60 owner, and regression-test that cross-owner wiring with
the real shell adapter action surface before collecting lifecycle amortization data again.
