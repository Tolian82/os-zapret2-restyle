**Authority:** approved native OPNsense compatibility TЗ/plan v1.2; **source-only revision** `VERSION=0.6.2`, `PLUGIN_REVISION=15`. This record is not owner appliance acceptance.

## Read-only single-run witness (prepared, not run)

`scripts/stage0-target-opnsense-readonly.sh` uses OPNsense `opnsense-version -a/-v`, FreeBSD and pkg ABI, actual installed package name/version/origin and cached **OPNsense-only** repo lookups with `REPO_AUTOUPDATE=false`, and `pkg which` for the generic and versioned Python paths. No repo update or installation occurs.

The old published private curl-impersonate FreeBSD ELF has PT_INTERP `/libexec/ld-elf.so.1` and six `DT_NEEDED` names: `libc++.so.1`, `libc.so.7`, `libcxxrt.so.1`, `libgcc_s.so.1`, `libm.so.5`, `libthr.so.3`. The witness checks fixed `/lib`, `/usr/lib`, `/usr/local/lib` candidate paths with metadata, SHA-256 and `pkg which`, and optionally observes the **read-only** `ldconfig -r` cache. It never executes the downloaded ELF or invokes `ldd` on it. A cache entry or file presence **cannot prove** binary ABI compatibility, actual dynamic-loader resolution, library provenance or the required Strategy Lab browser/QUIC capabilities. Non-listed paths can also exist in versioned library subdirectories, so negative direct-path observations are not definitive.

The old repository/backup report includes only existence/mode/hash and byte equality for `/usr/local/etc/pkg/repos/FreeBSD.conf` and `/var/db/zapret2-restyle/FreeBSD.conf.backup`. It now independently checks whether the current file's bytes are the exact old literal `FreeBSD-ports: { enabled: yes }` + newline, or a symlink/foreign/absent file. It **never prints repository file contents or credentials**, never restores or deletes files, and reports `REPO_OWNERSHIP=NOT_PROVEN_BY_THIS_PROBE` regardless of shape. No historical proof of who created these bytes or no subsequent human edit can be gained from a byte comparison.

## Test and execution scope

The shell test `scripts/test-stage0-target-opnsense-readonly.sh` checks syntax, required new status markers and disallowed mutation commands; executes the read-only script against an unqualified Linux host; and repeats with a fake `ldconfig -r` claiming `libgcc_s.so.1`, asserting that an ELF runtime PASS is **never** reported. Two local smoke scenarios are run by the developer before PR; CI executes the same exact test plus the full applicable regression matrix. A native OPNsense owner run has **not** occurred.
