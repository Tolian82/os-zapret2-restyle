# #1052 P2k8h — original post-credential-drop root reownership before IPFW

**Source candidate:** `v0.6.5_38`, 14 November 2026. **Import-only original-FD9 prospective backend, not an installed active observer/worker or published .pkg.**

## User-facing regression and before/after

A real single `dvtws2 --user=nobody` from the approved P2h **original shared-release observer preview** changes native hostlist file ownership during engine startup. P2g requires `root:nobody-primary-group 0660` on the producer `inbox.txt` and `debug.log`, not nobody-owned pending/worker data. The previous disposable native P2i experiment proved that a narrow post-drop root reownership **before IPFW** allows subsequent native raw/debug appends without relaxing the protected root owner. But the actual restoration was a *test-only pathname `os.chown`*, absent from reusable product backend. There was no shared code that could be safely called at the real original FD9 startup boundary.

P2k8h adds `backend/auto_detect_post_drop.py` as an import-only primitive to reuse **only** under the single original shared-FD9 lifecycle when recording/worker gates are eventually authorized. `native_capture_before_launch()` verifies the existing P2g parent, `root:nobody-group 0710` namespace, private pending (`root:root 0700`), worker lock if present, and exact prelaunch `root:nobody-group 0660` raw/debug file device/inode/link identities. It does not open payload data, create or truncate files.

After the same original engine is started and drops privileges, `native_restore_before_ipfw(witness, OwnerToken)` refuses unless on FreeBSD EUID 0, the original producer root is the canonical `/var/db/zapret2-auto-detect`, and the **real native P2b process token (PID, birth, absolute executable)** stays identical. The helper checks **both** file identities and protected P2g attributes **before the first write**, then opens each with `O_NOFOLLOW` and `fstat`, calls **`fchown(fd, root, nobody_gid)` only on the original matching inode**, and checks both files again, plus liveness, before traffic can be diverted. A swapped file/symlink, foreign uid/group, unsafe mode, dead/replaced process, broken queue lock or partial repair fails closed. This avoids changing an untrusted pathname after the initial inode proof.

## Exact test integration and limits

The **existing** `scripts/test-p2i-original-preview-native.py` is updated to use this backend primitive, removing its separate `_reattest_root_after_native_drop` helper. It captures the real pinned upstream `dvtws2` process's PID/FreeBSD birth/executable and calls the same backend **between the actual `--user=nobody` startup and installation of its two previously approved temporary loopback IPFW rules**. The test still establishes known-first-match versus unknown passive observer raw/debug once, on native OPNsense/FreeBSD. It must print `P2I_ORIGINAL_FD9_PREVIEW_NATIVE_REUSABLE_P2K8H_INODE_FD_REPAIR=PASS` and its preexisting native PASS markers. Source-only `scripts/test-auto-detect-post-drop.py` adds failures on replaced/symlinked files, unsafe modes, foreign worker lock and owner death before mutation; these join the existing fast CI/P2g scope. No new VM, daemon, configd action, journal, service, package or second engine.

**Proof boundary:** passing a disposable VM does not make this primitive a real installed original-FD9 callback. P2h active schema-2 observer generation, source-of-truth raw/debug creation on the *product* shared Apply, live PID/birth/FD binding, durable minute worker, old-generation drain/ACK and native owner appliance acceptance are still missing. Do not enable recording before durable consumption, or unbounded raw inbox growth is possible. `commit_authorized=false`, no manual config.xml, Voice, WAN, IPFW or Strategy Lab changes in installed code.
