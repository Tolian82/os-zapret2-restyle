# Security Policy

## Supported versions

`os-zapret2-restyle` is currently in pre-1.0 active development. The latest published stable release, the latest published testing prerelease
and the latest commit on `main` are actively maintained. Older releases and
prereleases should be upgraded before a defect is investigated. This support
policy was clarified by the owner on 13 November 2026; it does not equate
testing-package qualification with a stable release.

## Reporting a vulnerability

Do not publish credentials, private configuration, exploit details, or other
sensitive information in a public issue.

Contact the maintainer at:

```text
tolian82IPB@gmail.com
```

Include:

- affected commit or version;
- OPNsense version;
- a concise description;
- reproduction steps;
- potential impact;
- relevant logs with secrets removed.

Internal APIs and configuration formats may change before version 1.0.0.
