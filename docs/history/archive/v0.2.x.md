# v0.2.x — archive map

Status: **ARCHIVED / LEVEL 3 / READ ON DEMAND**

This compact map preserves the completed `v0.2.x` line without forcing its detailed chronology into
normal startup context. Original Git history, releases, devlogs, patch records, decisions and audits
remain intact and are the source for exact historical detail.

## Scope and chronology

- `v0.2.0–v0.2.2` — early stabilization of the post-`v0.1.x` plugin/package line.
- `v0.2.3` — configuration activation contract was enforced and autonomous patch delivery policy was
  documented.
- `v0.2.4` — lifecycle/locking work continued, including lifecycle-lock inheritance.
- `v0.2.5` and its package revisions — publication/preflight discipline, root-`csh` operator contract,
  replacement activation and service-state preservation were hardened.
- `v0.2.6` — plugin registration/integration work.
- `v0.2.7` — rebuild/packaging continuation.
- `v0.2.8` — service-state-preserving runtime setup and release/CI pipeline hardening completed the
  line before `v0.3.x`.

This is intentionally a summary, not a second copy of the patch-by-patch record.

## Handoff to v0.3.x

By the end of `v0.2.x`, activation/replacement and delivery behavior had been substantially hardened.
`v0.3.x` then moved the project toward richer GUI Zapret2 service management, diagnostics and the
Strategy Lab work that later became the main adaptive-search development line.
