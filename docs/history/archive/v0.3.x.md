# v0.3.x — archive map

Status: **ARCHIVED / LEVEL 3 / READ ON DEMAND**

This compact map closes the completed `v0.3.x` line. It does not replace or delete the original
release, devlog, patch, decision or verification records. Those detailed records remain available and
are loaded only when a current task needs their exact chronology or evidence.

## Scope and chronology

- `v0.3.0` — live-verified **Zapret2 Service** GUI/control surface: runtime state, stable upstream
  release selection, transactional install/reinstall/update/downgrade, service-state preservation and
  runtime-safe activation.
- `v0.3.1` — diagnostics corrective: negative/blocked Test Domain Connectivity results retained a
  complete report instead of becoming empty; owner live verification accepted the release.
- `v0.3.2` — engineering/publication-governance hardening without changing the accepted `v0.3.1`
  runtime behavior.
- `v0.3.3_N` — iterative Strategy Lab/blockcheck development and live-test hardening, including
  lifecycle/network/candidate/family/parameter work and the transition toward the Python Strategy Lab.
  Testing packages such as `v0.3.3_27` were deliberately prerelease candidates for owner-assisted
  live verification rather than stable release promotion.

The detailed `v0.3.3_N` patch sequence remains in the original records; this map intentionally avoids
copying that long narrative.
