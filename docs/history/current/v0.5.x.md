# v0.5.x — current working ledger

## 2026-10-13 — v0.5.2_2, полный общий Voice/Strategies candidate

Владелец поручил непосредственно программировать по плану; прежнее pending agreement заменено выполнением этапов. Общий `orchestrator_build_release(... shared-candidate ...)` использует существующие parser/targets/blob/generator/validator, создаёт корневые `traffic.conf` и `dvtws.args` для пяти Voice-сервисов + ordinary. Старый marker/prepend и отдельный native bundle в этом пути отсутствуют. Один release-local `voice-plan.json` описывает профили/capture и не является владельцем lifecycle.

Доказанно раздельные ordinary STUN IP/UDP scopes допускаются, пересечение/непроверяемая область явно отклоняется. Native dry-run при наличии engine использует staged lists; Lua execution/live packets этим не квалифицируются. Полный build локально проверен на всех пяти/каждом/all-OFF/global-OFF/ошибках; retained compiler/merge/release/activation checks проходят. Local Python 3.12; CI использует пакетный Python 3.13/Linux/FreeBSD. Код обновляет `_N` на 2, frontend/ТЗ/live appliance не меняются. Следующий этап — общий firewall, затем публичный Apply.
