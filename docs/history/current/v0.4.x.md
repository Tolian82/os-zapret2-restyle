The **second numeric component** is the `4` in `0.4.x`. The assistant must not initiate a change to
that component. A transition such as `v0.4.x -> v0.5.x` requires explicit owner version/transition
authority or separate owner approval and always includes a full project release.

A full project release can be requested without changing the second numeric component. Full release
means a verified package published into the project Pages/pkg repository for OPNsense Web GUI
installation, together with semantic tag/release assets/checksums and a complete human-facing
`README.md` review.

Testing `_N` packages remain a separate publication class and do not promote the Web/pkg repository.
