==================================================
CORRECTION
==================================================

`_25` retains the deterministic `42000+` plan as a preferred identity plan, but concrete
ports are leased independently immediately before each admitted warm batch.

For every candidate/endpoint flow:

1. keep its deterministic preferred source port when the host proves that port free;
2. if it is already in use, leave the foreign socket/process completely untouched;
3. select a unique free alternate above the deterministic plan using the existing audited
   `source-port-free` adapter boundary;
4. render and probe using that exact leased port, preserving the existing source-port-
   qualified IPFW rule, exact curl `--local-port`, exact pinned `--resolve`, counter-growth
   and cleanup attribution contract;
5. retain the endpoint-probe availability recheck as race protection;
6. if Model C becomes unavailable and Model B is entered, Model B performs a **fresh lease**
   rather than inheriting Model C's failed concrete port;
7. if the bounded alternate search cannot prove a free port, fail closed into the existing
   fallback chain rather than weakening attribution or terminating a foreign owner.

Lease evidence records preferred ports, actual leased ports, replacements and the explicit
foreign-port policy `skip-only`.

No Stage-60 timeout is increased in this patch. The source-port defect was corrected first so
that a larger timeout could not hide an avoidable Model-C -> Model-B -> Model-A fallback.

==================================================
FOLLOW-UP — ADAPTIVE BUDGET
==================================================

A separate follow-up must replace one-size-fits-all Strategy Lab timing with an **adaptive
budget derived from the actual eligible work matrix**:

`number of endpoints × IPv4/IPv6 × TLS/QUIC × Generic UDP × Standard/Extended mode`.

When IPv6, QUIC or Generic UDP are actually available/selected, the job must automatically
receive a reasonable additional budget proportional to the work it can perform. The design
must not be implemented by guessing one oversized global timeout. Budget admission and
stage/overall deadlines must remain finite, observable and cancelable.

`_25` intentionally does not implement this timing redesign. It first removes the confirmed
source-port collision amplification so later measurements represent real Model-C work rather
than accidental cold fallback.
