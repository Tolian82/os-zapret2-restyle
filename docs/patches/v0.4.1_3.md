## Accepted owner-live result

The owner-installed `_3` run completed all 27 startups: 9 BLOB-free, 9 built-in and 9
external-file trials. All adapter/sample/cleanup/restoration checks passed and the report ended
with `conclusion=measurement_accepted`.

Median stable readiness was `63.061 ms` BLOB-free, `62.652 ms` built-in and `62.566 ms`
external. Median ready and settled RSS was exactly `4360 KiB` for all three variants. The
pairwise median readiness differences were `-0.409 ms` built-in vs BLOB-free and `-0.495 ms`
external vs BLOB-free; these sub-1% differences are smaller than the observed within-variant
spread and do not establish a BLOB startup penalty.

The run used `cache_policy=natural-cache-no-drop`, so it is intentionally not a cold-cache
claim.

## Decision

Do not change production Model C BLOB loading from this result. The representative single
external `fake_tls_7.bin` declaration showed no material startup/readiness or RSS cost, and one
valid run cannot authorize a production architecture change.

The broader experiment authority still lists small-inline and several semantically compatible
external-resource coverage. If BLOB-loading optimization continues, that remaining scaling/
common-set question must be measured separately before any production change is considered.
