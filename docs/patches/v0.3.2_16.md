# Patch candidate `v0.3.2_16` — Persist Strategy Lab cancellation state

## Scope

Corrective Patch 2 implements only the persistent cancel-state contract. It does not yet terminate active stage 60, 70, or 80 child probes; that remains Corrective Patch 3.

## Changes

- Added a serialized atomic state-update boundary for Strategy Lab `status.json` mutations.
- Added `cancel_requested_at` to the job schema.
- Added `strategy_lab_request_cancel()` to persist `state=cancel_requested`, `cancel_requested=true`, the first UTC request timestamp, and a localized message.
- Made the cancel control file an atomic write.
- Made cancel responses return the exact persisted status snapshot.
- Made repeated cancel requests idempotent and preserve the original timestamp.
- Prevented later non-terminal job updates from clearing an existing cancel request.
- Kept completed and error jobs immutable under cancel.

## Regression coverage

The focused cancellation test verifies:

- English and Russian messages;
- persisted status and API response equality;
- stable timestamp on repeated cancel;
- valid JSON under concurrent stage updates;
- preservation through a late worker update;
- terminal-job immutability;
- cleanup of lock and temporary state files.

The test is included through the existing Strategy Lab job-contract aggregate and therefore runs in standard CI before the FreeBSD package build.
