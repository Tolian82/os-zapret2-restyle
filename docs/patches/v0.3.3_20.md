# v0.3.3_20 — Strategy Lab Migration Patch 3

## Scope

Migration Patch 3 moves Strategy Lab numbered-stage orchestration, wall-clock budgets,
cancellation orchestration, and terminal finalization policy from the sourced shell worker
to Python 3.13.

This patch deliberately does **not** move finite request/probe execution and parsing,
candidate/family algorithms, parameter expansion/stability algorithms, extended protocol
algorithms, or final result/shortlist generation. Those remain assigned to later migration
patches.

## Ownership after this patch

Python `strategy_lab_py/orchestrator.py` is authoritative for:

- stage order `00,10,20,30,40,50,60,70,80,85,90,99`;
- Standard and Extended absolute deadlines and stage-time arbitration;
- stage-80 shared deadline arbitration;
- cancellation detection and child process-group termination;
- timeout classification at the orchestration boundary;
- terminal outcome/state/report mapping;
- mandatory restoration through stage 90 on success, no-candidate, prerequisite exit,
  timeout, cancel, signal, or internal error;
- mandatory stage 99 terminal persistence;
- restoration-failure override to `RESTORE_FAILED`.

The existing `strategy_lab_worker.sh` becomes a thin production launcher into
`strategy_lab_python.py orchestrate JOB_ID`.

`strategy_lab_stage_adapter.sh` is the explicit transitional shell boundary for the
stage-specific OPNsense/FreeBSD and still-unmigrated Strategy Lab algorithms. It performs
an action requested by Python and returns one structured result; it does not own stage
ordering, deadlines, cancellation policy, or terminal finalization.

Patch-2 Python persistence remains authoritative for automated-job `status.json`,
`events.ndjson`, progress, cancellation evidence, and revision ownership. Private circular
session `state.json` remains shell-owned.

## Lifecycle and process safety

- the existing shared lifecycle lock remains authoritative;
- inherited lock fd 9 is preserved into Python and passed to stage adapters;
- active-job process ownership recognizes the Python orchestrator PID;
- cancel/timeout termination targets the active adapter process group;
- stage 90 still delegates lifecycle mutation/restoration to the audited shell lifecycle
  adapter;
- saved Traffic Strategy is not modified by the new orchestrator.

## Compatibility

The public Strategy Lab JSON schema, stage numbers, progress percentages, state/outcome
names, API/configd boundary, and evidence locations are unchanged.

The latest published and owner-tested package remains `_17`. `_20` is a migration source
candidate only until a separately authorized testing prerelease and owner-assisted live
gate.
