# v0.3.2_30 — Serialized Strategy Lab state

## Purpose

Prevent concurrent worker, cancellation, polling, lifecycle, and result writers from losing fields or reverting a terminal Strategy Lab result.

## Changes

- add a per-job `status.lock` transaction around every authoritative `status.json` read-modify-write;
- increment a monotonic `revision` for every state transaction;
- serialize cancellation, job state, stages, target contract, network, baseline, family, expansion, stability, shortlist, extended protocols, lifecycle evidence, budgets, and circular eligibility;
- serialize event appends with the same per-job lock;
- make terminal `completed` and `error` states irreversible by later cancel, stage, or worker updates;
- preserve the first cancellation timestamp and make repeated cancellation idempotent;
- add the focused concurrent state-race test to mandatory CI.

## Verification

`test-strategy-lab-state-race.sh` performs concurrent field updates, races cancellation against terminal completion, and verifies monotonic revisions plus terminal-state immutability.
