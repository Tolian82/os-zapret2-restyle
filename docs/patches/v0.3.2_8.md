# v0.3.2_8 — Strategy Lab TLS 1.3 family screening

## Scope

Patch 6 implements stage 50 only: one representative candidate for each approved TLS 1.3 Zapret2 family.

## Families

- multisplit;
- multidisorder;
- seqovl through a split instance with `seqovl=1`;
- fake using `fake_default_tls`;
- fake followed by multisplit;
- syndata without hostname filtering because SYN data precedes hostname discovery;
- hostfakesplit.

## Execution contract

- different families are never active concurrently;
- every family uses the isolated Patch-5 runtime;
- up to two required endpoints share the same active candidate;
- candidate timeout is five seconds;
- stage-50 timeout is 45 seconds;
- completed family results survive timeout or cancellation;
- stage timeout recursively terminates child probe processes before restoration;
- acceptance requires every required endpoint to pass;
- full teardown is verified before the next family starts.

## Exclusions

Parameter expansion, stability confirmation, shortlist/report, extended protocols, circular validation, GUI activation, and legacy Blockcheck removal remain later patches.

Package candidate: `os-zapret2-restyle-0.3.2_8.pkg`.
No tag, release asset, or pkg-repository publication is authorized.
