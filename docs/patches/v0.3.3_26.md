# v0.3.3_26 — Stage-50 candidate failure isolation

Status: **SOURCE CORRECTION / LIVE RETEST REQUIRED**

## Purpose

Correct the post-migration Scenario-1 failure observed on published/installed
`v0.3.3_25` without changing Strategy Lab ownership or search semantics.

The `_25` job `job.c0oydv` proved that the temporary candidate runtime was healthy and
that `seqovl` successfully reached `rutracker.org`, but Stage 50 still terminated after
only 4 of 7 family entries.

## Live evidence

Authoritative evidence:
`docs/verification/evidence/2026-08-08-v0.3.3_25-scenario-01-stage50-candidate-isolation.md`.

Decisive facts:

- family aggregate: `total=7`, `completed=4`;
- `accepted=["seqovl"]` and `all_pass=true` were already persisted;
- the successful candidate had endpoint match and IPFW interception evidence;
- candidate runtime readiness was stable and clean;
- Stage 90 restored the initial RUNNING service state.

The generic Stage-50 message therefore did not describe a global candidate-runtime startup
failure.

## Root cause

`strategy_lab_py/candidate.py` writes a structured result for a candidate-local error.
The compatibility candidate runner returns status 1 when that result has `error:true`.

Before `_26`, `strategy_lab_py/family.py` treated every nonzero candidate-runner status as
a fatal family-screening exception before reading that structured JSON. One candidate-local
error could therefore abort all remaining family entries and lose continuation after an
already accepted family.

## Correction

`strategy_lab_py/family.py` now:

- removes the old per-candidate JSON before each launch;
- reads fresh structured candidate evidence even when the compatibility runner returns
  nonzero;
- treats nonzero status plus `error:true` as a rejected candidate, retaining its diagnostic
  result and `runner_status`;
- continues screening the remaining family catalog;
- still treats missing/invalid structured evidence, or nonzero status without structured
  candidate-error evidence, as a true screening failure;
- preserves cancellation and timeout semantics.

## Regression

New focused regression:
`scripts/test-strategy-lab-stage50-candidate-isolation.sh`.

It proves that an accepted candidate followed by a structured `error:true` / exit-1
candidate does not abort the stage and that subsequent candidates are still screened.

Existing candidate/runtime/family tests remain mandatory.
