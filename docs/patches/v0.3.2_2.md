==================================================
CHANGED
==================================================

- Required all blobs, one tree, one atomic commit, and validation before branch creation.
- Prohibited attempt branches with suffixes such as `-clean`, `-final`, `-atomic`,
  `-fixed`, `-retry`, and `-publish`.
- Added automatic deletion of the merged same-repository pull-request branch.
- Required post-merge branch-absence verification.
- Distinguished package patch `vX.Y.Z_N` from project release `vX.Y.Z`.
- Corrected project state after publication of v0.3.2.
- Added focused CI coverage for the branch-hygiene contract.

==================================================
UNCHANGED
==================================================

Plugin runtime, GUI behavior, service lifecycle, diagnostics behavior, `VERSION`, and
published v0.3.2 release artifacts are unchanged.
