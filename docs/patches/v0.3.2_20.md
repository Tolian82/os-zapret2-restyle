# Patch candidate `v0.3.2_20` — Strategy Lab shared time budgets

## Scope

Corrective Patch 6 enforces one absolute overall search deadline and one shared stage-80 budget. Semantic restoration remains Corrective Patch 7.

## Changes

- Added a worker-owned budget module with portable UTC timestamp generation.
- Recorded standard and overall deadlines when the worker starts.
- Enforced a 150-second standard search phase.
- Added a 120-second extended allowance only in extended mode.
- Clipped stages 30, 40, 50, 60, and 70 to the remaining standard-phase time.
- Established one shared stage-80 deadline for TLS/HTTP, QUIC, and UDP branches.
- Prevented a new stage-80 branch from receiving a fresh 120-second timeout.
- Prevented stage 85 from starting after the overall search deadline.
- Kept stage 90 cleanup and restoration outside the search deadline.

## Regression coverage

The deterministic time-budget test verifies persisted UTC deadlines, standard and extended totals, remaining-time clipping, shared stage-80 consumption, expiry behavior, and worker wiring. It is included in the aggregate domain-diagnostics contract.
