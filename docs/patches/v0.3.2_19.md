# Patch candidate `v0.3.2_19` — Truthful Strategy Lab terminal results

## Scope

Corrective Patch 5 fixes terminal `state`, `outcome`, stage-99 status, and localized final messages. Time-budget enforcement remains Corrective Patch 6.

## Changes

- Added one worker-owned terminal-result contract.
- Classified a non-empty final shortlist as `SUCCESS`.
- Classified an empty valid shortlist as `NO_CANDIDATE`.
- Kept `TARGET_ACCESSIBLE` and controlled `PARTIAL` results terminal `completed`.
- Classified `TIMEOUT`, `ERROR`, and `RESTORE_FAILED` as terminal `error`.
- Marked stage 99 `FAIL` for error outcomes and `PASS` for completed outcomes.
- Made restoration failure override any requested success or partial result.
- Generated final text from language, mode, outcome, cancellation state, and shortlist count.
- Removed active dependence on cascading `*_FINAL_MESSAGE` variables.

## Regression coverage

The focused terminal-result test verifies standard and extended success, no candidate, accessible target, cancellation, prerequisite partial, timeout, internal error, and restoration failure. It asserts persisted state/outcome, cancel flag, stage-99 status, and message truthfulness.

Lifecycle tests now expect `NO_CANDIDATE` for their valid empty-shortlist fixture and terminal `error` for internal or restoration failures.
