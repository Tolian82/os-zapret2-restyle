# v0.3.2_28 — Hard Strategy Lab deadline

## Purpose

Guarantee a terminal timeout and restoration attempt even when execution does not return through an individual stage timeout.

## Changes

- start a parent-aware watchdog before worker stage execution;
- enforce a 150-second standard deadline and a 270-second extended deadline;
- on expiry, request cancellation of the active child runner, use the persisted current stage, and enter the existing TIMEOUT cleanup and restoration path;
- stop the watchdog before normal or abnormal final restoration so it cannot interrupt restoration;
- treat signals received during finalization as no-ops rather than exiting early;
- add the focused hard-deadline test to the mandatory domain-diagnostics CI suite.

## Verification

`test-strategy-lab-hard-deadline.sh` verifies deadline expiry, persisted-stage selection, and child-cancellation request. The central diagnostics contract invokes the test in required CI.
