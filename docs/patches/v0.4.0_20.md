# v0.4.0_20 — Controlled parallel Model B candidate probes

Status: source experiment candidate.

Purpose: measure the last unexecuted Model B optimization from the approved Strategy Lab experiment plan: true simultaneous candidate probes after sequential warm-worker coexistence and exhaustive replay have both been proven deterministic.

Scope is experiment-only. Production Strategy Lab remains Model A.

The experiment reuses the exact persisted `NO_CANDIDATE / graph_exhausted` Stage-60 corpus and the owner-proven three-worker warm batch boundary. Up to three candidate workers are probed concurrently. Pinned endpoints within one candidate remain sequential.

Parallel traffic ownership cannot reuse the sequential `_19` rule contract because multiple rules would otherwise match the same `from me -> selected_ip:443` flow. `_20` therefore assigns every candidate/endpoint probe a unique controlled TCP source port. Each temporary IPFW rule matches the exact source port and exact pinned destination before diverting to that candidate's dedicated worker. The requested source port is unique across the complete benchmark and must be free before the probe. Rule counter growth plus the exact source-port selector and pinned remote endpoint are retained as attribution evidence.

Required gates:

- same current ResourceInventory and exact persisted corpus/order;
- all warm batches ready with unique worker PID/divert identity and numeric RSS;
- source-port plan unique and bounded;
- at most three candidate tasks concurrently;
- candidate tasks in a multi-worker batch overlap in wall time;
- endpoints remain sequential within each candidate;
- every endpoint retains exact pinned IP and dedicated source-port route attribution;
- no cold no-candidate result becomes PASS;
- workers remain healthy through each batch;
- batch cleanup and final semantic restoration are verified;
- experiment remains `production_approved=false`.

No CPU-count gate is used. Logical CPU count is recorded as measurement metadata only so the experiment remains comparable across 2-core, 4/6-core and larger OPNsense appliances.
