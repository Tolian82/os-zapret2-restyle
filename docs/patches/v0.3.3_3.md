# v0.3.3_3 — Idle Diagnostics reload

## Scope

Return the Strategy Lab section to its initial state when the Diagnostics page is opened after a terminal completed or failed job.

## Defect

Automatic `status -` discovery selected `latest.job` when no active job existed. A historical terminal error was therefore rendered again after every page reload and looked like the current Strategy Lab state.

## Changes

- automatic status discovery now returns only a valid active job;
- no active job produces `{ "status": "idle" }` even when retained terminal history exists;
- explicit status/result requests by validated job ID still expose retained evidence;
- active jobs continue to resume after reload;
- documentation and the live scenario 15 contract now distinguish active recovery from terminal history.

## Verification

- focused active/terminal reload regression;
- complete Strategy Lab corrective matrix;
- full repository CI;
- FreeBSD 15 package build and manifest verification.
