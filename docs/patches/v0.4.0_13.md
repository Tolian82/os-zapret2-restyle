# v0.4.0_13 — Model B clean-preflight corrective

## Purpose

This corrective packaged patch fixes the first owner-live blocker found while starting the
experiment-only Model B coexistence harness from `v0.4.0_12`.

The owner appliance had all required prerequisites available:

- `ipfw` and `ipdivert` were loaded;
- `net.inet.ip.fw.enable=1`;
- `dvtws2` and `daemon(8)` were executable;
- dedicated Model B rules `19128`–`19130` were absent;
- dedicated divert ports `9990`–`9992` were unused.

Despite that clean state, `strategy_lab_model_b.sh` stopped before worker launch with
`ERROR: Model B dedicated ports/rules are not available`.

## Root cause

`strategy_lab_model_b_adapter.sh::preflight()` used negative availability predicates in its
final loop:

```sh
for _mb_port in $MODEL_B_PORTS
do
    port_in_use "${_mb_port}" && return 1
done
```

For a free port, `port_in_use` correctly returns status `1`. Because the function had no
explicit success return after the loop, POSIX shell propagated the status of the final
`port_in_use 9992 && return 1` list as the status of `preflight()` itself. Therefore a
fully clean Model B port set produced a false preflight failure.

The owner `sh -x` trace reproduced this exact path: every prerequisite passed, all three
rules were absent, all three ports were free, and the function finally exited with status
`1` immediately after the `9992` availability check.

## Fix

`preflight()` now ends with an explicit `return 0` after all rule/port conflict checks have
completed without finding a conflict.

This does not weaken the safety boundary. Existing early failures remain unchanged:

- missing/disabled firewall prerequisites still reject;
- missing runtime binaries still reject;
- any occupied dedicated rule still rejects;
- any occupied dedicated port still rejects.

## Regression

A new executable shell regression `scripts/test-strategy-lab-model-b-preflight.sh` invokes
the real Model B adapter with deterministic system-command stubs and proves all three
cases:

1. clean rules and clean ports return success;
2. an occupied dedicated rule returns failure;
3. an occupied dedicated port returns failure.

The test is automatically included by the mandatory Strategy Lab corrective matrix.

## Scope boundary

No Model B measurement logic, worker topology, routing rules, candidate selection,
restoration contract, search behavior, timeout constants, GUI behavior, Model C work or
production warm-worker approval changes in this patch.

`VERSION` remains `0.4.0`; `PLUGIN_REVISION` advances exactly once from `12` to `13`.
