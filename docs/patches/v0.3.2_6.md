==================================================
TYPE
==================================================

This is Strategy Lab Patch 4 and an ordinary package patch. It is not a project release
and creates no tag, GitHub Release, release asset, or pkg-repository publication.

==================================================
OBJECTIVE
==================================================

Implement Strategy Lab stages 00, 30, and 40:

- validate and classify a domain or IPv4 target;
- register explicit required endpoints;
- determine usable IPv4, IPv6, and QUIC branches;
- test the target cleanly without Zapret2;
- stop early when bypass is not required;
- enforce stage budgets and preserve exact lifecycle restoration.

==================================================
IMPLEMENTATION
==================================================

- Added `strategy_lab/target.sh` for normalization, validation, classification, and
  required-endpoint generation.
- Added `strategy_lab/request.sh` for bounded DNS, TLS 1.3, IPv6 route, QUIC, and TCP
  operations.
- Added `strategy_lab/result.sh` for structured endpoint and baseline results.
- Added `strategy_lab/probe.sh` for network capability and clean-baseline orchestration.
- Added `strategy_lab_probe_runner.sh` as the executable stage boundary used by
  `timeout(1)`.
- Extended job schema with target type, endpoints, network capabilities, and baseline.
- Added `TARGET_ACCESSIBLE`, valid prerequisite failures, and `TIMEOUT` reporting.
- Kept stage 90 mandatory on all new paths.

==================================================
NETWORK CONTRACT
==================================================

- IPv4 control: explicit TLS 1.3 GET to `yandex.ru`.
- IPv6: available only with a default IPv6 route and successful IPv6 control request.
- QUIC: fixed `yandex.ru:443`, IPv4, ALPN `h3`, two seconds, result determined only by
  command exit status.
- Domain baseline: DNS A, optional AAAA, explicit TLS 1.3 HTTP/1.1 GET, no retry, no
  certificate bypass, bounded redirects and response.
- IPv4 target baseline: direct TCP/443 only.
- Stage 30 budget: six seconds.
- Stage 40 budget: five seconds.
