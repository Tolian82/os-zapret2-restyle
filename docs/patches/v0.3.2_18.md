## Scope

Corrective Patch 4 replaces active load-order hook orchestration with one explicit search-stage machine. Terminal outcome classification and shared time budgets remain separate corrective patches.

## Changes

- Added `worker_stage_machine.sh` with explicit stages 60, 70, 80, and 85.
- Enforced the active order `60 -> 70 -> 80 -> 85` after stage 50.
- Marked stage 80 explicitly `SKIPPED` in standard mode.
- Delayed final shortlist construction until stage 80 has passed or been skipped.
- Replaced worker cancel/error/timeout skip calls with a unique worker-owned skip helper.
- Removed all active calls to the old `strategy_lab_skip_unfinished()` and `strategy_lab_skip_remaining()` hooks.
- Kept existing family, expansion, stability, extended, QUIC, and UDP computation helpers unchanged.
