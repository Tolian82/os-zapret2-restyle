# v0.3.2_35 — Unify replay-verified protocol results

## Purpose

Make the final Strategy Lab result reflect all protocol branches that already produced a
confirmed working candidate, without weakening the exact-profile replay gate or feeding
incompatible profiles into circular validation.

## Changes

- generalize complete profile construction and validation for TLS 1.3, TLS 1.2, HTTP,
  QUIC, and configured UDP;
- generalize the exact-profile replay runner to activate the matching TCP, QUIC, or
  generic UDP candidate runtime;
- collect Stage 70 TLS 1.3 stability results and Stage 80 working results through one
  source contract;
- deduplicate and order sources by protocol rank, profile size, and candidate ID;
- publish up to five items, using one best verified profile per available protocol in
  extended mode;
- retain TLS 1.3-only standard-mode behavior;
- use static replay-verified selected IPs for generic UDP domain profiles;
- add protocol, transport, port, L7, selected-address, and replay evidence to every item;
- separate the unified display list from the TLS 1.3-only circular candidate list;
- preserve compatibility with historical TLS 1.3-only shortlist files;
- wire the focused unified-shortlist test into mandatory CI.

## Verification

`test-strategy-lab-unified-shortlist.sh` verifies all five protocols, deterministic
ordering, protocol-specific profile headers, three replay attempts per source, generic UDP
IP selection, standard-mode isolation, and the TLS 1.3 circular boundary.

The revision-35 product tree passed complete project validation and the FreeBSD package
build at source SHA `4525b2dc333b1e3bd3b165c587dd68169c09f73d`.
