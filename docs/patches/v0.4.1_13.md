## Scope

This patch does not reopen model selection and does not change adaptive search semantics.

## Source change

- add `strategy_lab_py/stage60_model_c_production.py` as the normal production Stage-60 owner;
- route packaged `strategy_lab_python.py stage60-parallel ...` through that owner;
- reuse the existing proven Model-C `_bucket_batch` engine and the authoritative Stage-60 planner;
- translate `ModelCInfrastructureError` into `ModelCOnlyInfrastructureError`, a structural `Stage60ParallelError` that is deliberately not `WarmInfrastructureError`;
- therefore prevent the legacy Model-B/cold-Model-A fallback handler from consuming a normal production Model-C infrastructure failure;
- persist `model_c_only=true` and `cold_fallback_available=false` in Stage-60 result evidence when a result file exists;
- keep explicit `model-b|parallel|cold` overrides as reference/benchmark/test tooling only;
- advance `PLUGIN_REVISION 12 -> 13`, keeping `VERSION=0.4.1`.
