# v0.4.0_15 — FreeBSD process-query selection corrective

## Scope

One FreeBSD process-query compatibility defect only. Strategy Lab full-process scans use the
historical BSD shorthand selector `ax`, while the shared `process_query.sh` platform adapter
already prepends FreeBSD `-xww`. On the owner appliance that combination becomes
`/bin/ps -xww ax -o pid= -o command=` and FreeBSD rejects it with
`ps: illegal argument: ax`.

The affected scan surface includes the shared Strategy Lab candidate-runtime sweep and the
experiment-only Model B dedicated-port process fallback. Both inherit
`STRATEGY_LAB_PS_BIN=process_query.sh` from `backend/common.sh` in production.

## Root cause

`process_query.sh` deliberately owns the FreeBSD no-TTY/wide-output flags so detached
daemon children remain visible and command lines are not truncated. Its non-FreeBSD path is
transparent. The adapter did not, however, normalize the legacy leading `ax` selector used
by Strategy Lab before combining it with its own dashed FreeBSD flags.

The defect is therefore at the platform-adapter interface, not in Model B worker topology,
hostlist access, routing, probing, or lifecycle ownership.

## Change

- advance `PLUGIN_REVISION` from `14` to `15`;
- on FreeBSD only, when the first caller argument is exactly `ax`, translate it to `-A`
  before executing native `ps` with the existing `-xww` flags;
- leave every other caller argument unchanged;
- leave the non-FreeBSD process-query path completely transparent;
- extend the existing FreeBSD process-query regression so the legacy Strategy Lab
  all-process query must become `-xww -A ...`, must contain no bare `ax`, and the Linux
  compatibility path must still preserve `ax` unchanged.

## Explicit non-scope

This patch does not change:

- Model B candidate selection, ports `9990–9992`, rules `19128–19130`, worker count,
  routing, probe ordering, RSS collection, stop/death behavior, or restoration semantics;
- the `_14` bounded post-drop hostlist traversal lease;
- the separately confirmed Model B fail-fast/control defect after
  `all_workers_ready=false`;
- normal candidate strategy generation, time budgets, adaptive search, or result logic;
- Model C, source-port dispatch, preload policy, or production approval of a warm runtime.

## Verification contract

Source/CI must prove:

1. production backend wiring still routes Strategy Lab process inspection through the
   shared `process_query.sh` adapter;
2. FreeBSD PID-specific queries still receive `-xww` unchanged;
3. a leading Strategy Lab `ax` query is normalized to dashed `-A` before native FreeBSD
   `ps` execution and no bare `ax` remains;
4. non-FreeBSD callers remain unmodified;
5. the canonical Strategy Lab corrective matrix and FreeBSD 15 package verification pass;
6. owner-live Model B acceptance remains pending until `_15` is installed and the retained
   `job.TtZeaH` experiment is repeated. A future Model B `accept` remains experiment-only.
