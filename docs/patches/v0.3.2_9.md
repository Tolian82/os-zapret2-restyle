# v0.3.2_9 — Strategy Lab accepted-family parameter expansion

## Scope

Patch 7 implements numbered stage 60. It expands parameters only inside TLS 1.3 families accepted by stage 50.

## Contract

- accepted families are the only eligible families;
- different candidate strategies never run concurrently;
- every candidate uses the isolated Patch-5 runtime;
- up to two required endpoints share one active candidate;
- each candidate has a five-second limit;
- the stage has a 60-second limit;
- every completed result is persisted atomically;
- timeout is a rejected candidate, not an internal error;
- expansion stops after five working candidates or catalog exhaustion;
- mandatory cleanup and exact Zapret2 restoration remain unchanged.

## Catalog boundaries

The catalog varies split positions, sequence overlap, fake repetition or TLS modification, fake-plus-split position, SYN data payload, and hostfakesplit options only within the family already accepted by stage 50.

## Exclusions

Stability confirmation, shortlist/report, TLS 1.2, HTTP, QUIC, arbitrary UDP, circular validation, GUI activation, and legacy Blockcheck removal remain later patches.
