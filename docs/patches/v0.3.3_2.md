# v0.3.3_2 — FreeBSD daemon process-state correction

## Scope

Correct the live Strategy Lab stage 10 failure where a healthy Zapret2 runtime was classified as incomplete on OPNsense/FreeBSD.

## Root cause

The process identity paths invoked FreeBSD `ps` without `-x`. FreeBSD therefore omitted daemon processes without controlling terminals. Both dvtws2 and `supervisor_loop.sh` were running, but semantic evidence reported `child_running:false` and `supervisor_running:false`.

The process queries also lacked unrestricted command width, creating a second risk of false identity mismatches from truncated arguments.

## Changes

- add `process_query.sh`, which invokes native `ps` with `-xww` on FreeBSD and preserves the caller's selection semantics on other systems;
- route backend runtime and Strategy Lab semantic PID inspection through that wrapper;
- route launcher worker and circular owner PID inspection through the same wrapper;
- preserve injectable process binaries and operating-system identity for deterministic tests;
- add a regression test that returns daemon process data only when FreeBSD `-xww` is present and rejects injecting the BSD selector on Linux;
- advance the package revision to `0.3.3_2`;
- record the failed `0.3.3_1` live attempt without claiming a PASS.
