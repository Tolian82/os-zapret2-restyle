# v0.3.2_14 — Strategy Lab circular validation

Patch 12 adds a temporary live-validation session for the stable Strategy Lab shortlist.

- accepts only completed domain jobs with three to five candidates;
- builds one upstream Zapret2 `circular` profile;
- keeps different shortlisted strategies inside one temporary dvtws2 process;
- uses target-scoped outbound and inbound TCP/443 interception;
- exposes start, status, and stop configd actions;
- stops automatically after a bounded TTL;
- never writes the saved Traffic Strategy;
- cleans temporary runtime and firewall state;
- restores RUNNING to RUNNING and STOPPED to STOPPED;
- reports `restore_failed` instead of a false successful stop when exact restoration fails.
