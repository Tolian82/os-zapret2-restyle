# v0.3.2_39 — Guard Settings during Strategy Lab ownership

## Purpose

Complete hardening finding 12 by preventing Settings Apply from persisting configuration
while Strategy Lab, circular validation, or another Zapret lifecycle operation is active.

## Changes

- add a fail-closed lifecycle guard script and configd action;
- identify automated, circular, and raw lifecycle-lock ownership;
- treat circular `restore_failed` as blocking;
- expose a read-only Settings lifecycle endpoint;
- check ownership before model mutation and again before save;
- retain locked reconfigure and rollback for the residual race after the second check;
- add mandatory dynamic and controller-contract tests.

## Verification

- shell and PHP syntax validation;
- `sh scripts/test-strategy-lab-settings-guard.sh`;
- complete Strategy Lab and Settings contract suite;
- full CI and FreeBSD package build.
