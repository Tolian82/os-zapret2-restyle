# v0.4.1_14 — explicit Strategy Lab QUIC control and Generic UDP validation UX

**Status:** SOURCE CANDIDATE
**Date:** 2026-08-15

## Owner decision

The owner explicitly superseded the old QUIC capability-gating behavior.

Current product rule:

- add persisted `Enable QUIC` checkbox below `Generic UDP (optional)` in Extended mode;
- default OFF;
- OFF disables QUIC candidate testing;
- ON enables QUIC candidate testing;
- Stage-30 QUIC reachability/capability detection may remain diagnostic but cannot decide whether Stage-80 QUIC candidates run;
- ON must run QUIC candidates even when ordinary QUIC is blocked by the ISP.

The same live session exposed an input UX defect: selecting 2–3 MB Generic UDP files and pressing Run appeared to do nothing. The payload contract remains `1..4096` bytes; `_14` makes invalid pair/size input fail visibly before the prior result/UI state is cleared.

- bump `PLUGIN_REVISION` to `14`;

- add persistent Strategy Lab setting API;
- add Diagnostics `Enable QUIC` checkbox and load/save behavior;
- pass explicit QUIC choice through start API/configd/launcher;
- persist immutable job-local `quic-enabled` value;

- remove network-capability execution gates from Python production and shell/reference QUIC runners;
- keep Stage-30 `quic_ipv4` as diagnostic evidence only and correct its presentation;
- validate Generic UDP port/file pair and browser file size before resetting/starting Strategy Lab UI;
- retain strict backend Base64 and decoded-size validation.
