## Owner decision

The owner explicitly superseded the old QUIC capability-gating behavior.

Current product rule:

- add persisted `Enable QUIC` checkbox below `Generic UDP (optional)` in Extended mode;
- default OFF;
- OFF disables QUIC candidate testing;
- ON enables QUIC candidate testing;
- Stage-30 QUIC reachability/capability detection may remain diagnostic but cannot decide whether Stage-80 QUIC candidates run;
- ON must run QUIC candidates even when ordinary QUIC is blocked by the ISP.

The same live session exposed an input UX defect: selecting 2–3 MB Generic UDP files and pressing Run appeared to do nothing. The payload contract remains `1..4096` bytes; `_14` makes invalid pair/size input fail visibly before the prior result/UI state is cleared.
