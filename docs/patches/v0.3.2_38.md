# v0.3.2_38 — Serialize circular ownership and recovery

## Purpose

Complete hardening finding 11 by preventing concurrent circular starts, rejecting reused
PIDs, and restoring stale circular sessions before another lifecycle transaction begins.

## Changes

- add a dedicated circular launcher lock;
- close the launcher lock descriptor before daemon execution;
- persist session owner identity with PID and process-start token;
- refresh ownership after worker `exec`;
- require matching owner identity for an active session;
- recover an ownerless stale session using only session-local runtime and lifecycle
  evidence;
- verify semantic restoration before clearing the active pointer;
- keep `RESTORE_FAILED` sessions active to block unsafe automatic retry;
- route circular lifecycle status and restoration fields into session `state.json`;
- add the owner/recovery test to the mandatory diagnostics suite.

- circular and end-to-end contracts;
- complete project CI and FreeBSD package build.
