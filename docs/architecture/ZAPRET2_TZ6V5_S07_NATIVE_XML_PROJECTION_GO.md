## Scope and explicit exclusions

- This stage implements an **in-memory requested-settings projection**, not S08 effective compiler, old/native generation parity, diff planner, S09 immutable root JSON manifest, GUI Apply, lifecycle executor or source selectors execution. `SourceId` stores registered identity and storage key; file-backed list *contents* remain solely with original registry/storage and original P1/CAS/ACK. Never claim a compiled DPI profile or successful DPI bypass.
- The adapter has **no process/FD9 writer**, no original Config writer replacement, no shell calls, no IPFW mutation or hidden Start; original `wan_preflight` and `config_resolve_interface` remain native authority. No pfSense XML implementation has been made.
- The native test is on an **isolated disposable OPNsense 26.7**, not the user's physical firewall. Earlier true assigned TUN/OPT evidence qualifies the unchanged resolver, not a newly performed S07 IPv4-less physical experiment. No public `os-zapret2-restyle-0.6.5_190.pkg` or `_191.pkg`; no owner-device changes, no stable release.
- Lab Stage90 original semantic restoration issue [#1224](https://github.com/Tolian82/os-zapret2-restyle/issues/1224) remains ordered S15, Auto issue [#1223](https://github.com/Tolian82/os-zapret2-restyle/issues/1223) remains S16, CLI force/reload and native reload error handling belong to later stages. A passed S07 neither repairs nor authorizes any of these.

**Formal S07 GO:** the original saved XML → deterministic strictly typed, registered-source, non-authorizing neutral projection is physically qualified **without changing Config/FD9/pkgdb/PID/engine/IPFW**. The next approved scope is **S08 — pure target/resource/Voice compiler and semantic action planner**, preserving exact S03 real-generator parity, native profile first-match and active ordinary IPFW range `19000–19099`; no runtime mutations until later ordered stages.
