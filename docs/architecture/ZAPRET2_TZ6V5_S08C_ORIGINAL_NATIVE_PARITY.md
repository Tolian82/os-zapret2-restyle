## What changed

New import-only `backend/neutral_native_parity.py` **does not generate** final `dvtws.args`, make a synthetic source map, authorize any runtime action or choose native numbers. It consumes S07 immutable RequestedConfig, S08a TargetProjection, S08b ResourceProjection, and **real, detached, original** producer artifacts (actual `dvtws.args`, `traffic.input`, `voice.conf`, `voice-plan.json`, and the genuine original capture-only Auto source map).

- Rechecks **original** `voice_capture_plan.compile_capture_plan` against the exact original `voice-plan.json`; logical saved WAN is compared to the plan, physical WAN **is supplied by original native producer**, not guessed here. Ordinary managed IPFW range must be exactly **19000–19099**, Voice rules occupy its beginning and ordinary two-rule reservation begins immediately afterwards. Lab 19100–19131 and future 19140–19200 remain separate and untouched.
- Uses the original `global_exclusions.segments` native profile parser and original `auto_detect_origin_map.plan_learning_tier` on the **actual** old argv and source map, with an additional **independent** `auto_detect_owner._valid_learning_proposal` check of the generated *nonactivating* schema3 proposal. The canonical producer determines first-match order, native numbering, eligible known YouTube/User learning clones, all generated exclusions and debug/inbox identity. No appended observer or implicit `HOSTLIST:auto`.
- Explicitly correlates original Auto map source number, original source SHA, authored selectors and native normalized selector to S08a immutable projections. Voice prefix identity/hashed args cross-checks S08b, and original manifest's Voice/IPFW capture is strictly compared to the current producer output.
- `auto` source map is required and must match input strategy and exact argv SHA. For `list`/`all`, the old original generator does NOT emit an origin map; the witness returns `ORIGINAL_NONAUTO_NO_SOURCE_MAP` and refuses forged attribution, rather than inventing one.
- Output: frozen hash-only/no-raw-user-data witness with `authorization=NONE`, `physical_transition_allowed=False`. It cannot establish source file owner, inode, Config revision, live process, original FD9 epoch, seal, safe reload or Apply.
- Eight source-only tests in `scripts/test-tz6v5-s08c-original-native-parity.py` invoke **actual** existing P2e `OriginalSharedGeneration::build` / original `orchestrator_build_release` on disposable user-owned temp directories, and check native Voice ON/OFF, first-match YouTube/User, default selectors no learning, mixed IPSet no learning, `list/all` no-map behavior, global HOSTLIST/IPSet exclusion ordering, and forged argv/Voice plan/source-map/saved Target Mode/ordinary IPFW range negative refusals. Existing P2e/S03 evidence is reused; no extra VM matrix.
- No engine reread tests (upstream documented feature is accepted), FD9, Config, IPFW commands, GUI changes, PHP limits, process operations or owner OPNsense changes.
